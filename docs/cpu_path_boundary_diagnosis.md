# 近接経路の境界到達を診断

前回の平均反射一致実験で利用不能となった動的側29件を全件再生成し、探索初期値の増加と最小経路間隔の緩和を診断した。今回の結果は、単純な初期値不足よりも、近接した2経路の識別が不安定になる問題と整合する。受信機・校正ゲート・利用不能の判定は変更していない。

## 方法

対象は `output/cpu-matched-dynamic-reflection/evaluation.jsonl` の動的側利用不能全29レコード。26件は経路間隔の下限0.01 chip、残り3件は局所遅延情報の不足だった。直達遅延の探索窓端への到達ではない。条件をまたいで同じ雑音実現を共有するため、独立な29標本とは扱わない。既知の失敗を使う事後診断であり、未知データでの改善評価ではない。

既存と同じ雑音重み、複素振幅の変数消去、正規化残差二乗和と解析勾配を再構成した。まず元のフィット位置で局所標準偏差が既存実装と一致することを全件確認。直達遅延41点と経路間隔の候補から損失の小さい32初期値を選び、元の推定位置も加えた33初期値で再探索した。最大反復は300。

比較は (1) 同じ探索範囲、(2) 最小経路間隔のみ0.01から0.001 chipへ緩和。実質的な改善を `元の損失 - 新しい損失 > 1e-9 * max(1,元の損失)` と事前定義した。シミュレーションの真の遅延は観測損失の参考値を計算する用途に限り、初期値には使っていない。変更した探索に校正済みゲートを適用したり、測距を利用可能に変更したりしていない。

## 結果

| 診断 | 同じ探索範囲 | 最小間隔0.001 chip |
|---|---:|---:|
| 元の損失より実質的に小さいケース | 0 / 29 | 25 / 29 |
| 最小経路間隔付近に達したケース | 26 / 29 | 24 / 29 |
| 最小損失の候補が収束を報告しなかったケース | 3 / 29 | 2 / 29 |

複数初期値での局所探索であり、大域最適解を保証しない。収束しなかった候補も隠さず保存した。既存受信機の等価解選択ルールとは異なり、この診断は最小損失候補を収束状態とともに記録するだけであり、利用可能な解として採用しない。

最小間隔を緩めても、局所遅延標準偏差は全29件で既存の0.1 chip（約29.3 m）上限を超えた。境界チェックだけを外しても、遅延情報のガードを通過する結果にはならない。この局所標準偏差はモデル内の指標であり、測距誤差の保証された信頼区間ではない。

2本の推定波形それぞれのノルムの和を、合成波形のノルムで割った打ち消しの指標は、元の解で8.27–31.96、間隔緩和後で11.49–319.27。経路間隔を縮めると、大きい2本の波が相互に打ち消し合って観測を説明する解になる。

代表例（0.7 Hz・初期位相π・replica 520000）では、間隔0.01→0.001 chipに対して損失は965.418500→965.418150とわずかに減る一方、局所標準偏差は0.173→1.753 chip、打ち消し指標は29.48→294.48へ増えた。損失の微小な減少を、物理経路の推定精度向上とみなせない。

この結果は、近接経路のほぼ同じ形の波形と自由な複素振幅が生む識別の不安定さを示唆する。すべての失敗原因を確定したわけではない。次の候補は、200 ms平均に潰さず、ブロックごとの反射位相変化を使って経路を分離するモデル。実装する場合は新しい推定器として独立に評価し、モデル選択を変えるなら帰無校正もやり直す。
