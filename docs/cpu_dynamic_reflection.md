# 時間変化する反射波と固定した受信機の検証

反射波の位相を時間変化させる合成信号生成と、既存の雑音推定・順位ゲートを変更せず評価する実験を追加した。今回の条件では測距性能の低下は観測しなかった。ただし積算による反射の相殺が含まれ、一般的な動的マルチパスへの頑健性を示す結果ではない。

## モデルと事前固定

PRN1、白色複素Gaussian雑音、基準C/N0 37 dB-Hz、片側帯域3.6828 MHz、20 msブロック10個。直達波は静止し、反射は電圧比0.8、過剰遅延0.1 chip、初期相対位相0。反射の相対ドップラーを0、1、5、10 Hzとした。別に反射なし対照を設け、各128件、計640件。条件間で真の直達遅延・共通位相・雑音を共有する新規seedを用いた。

ブロックkの反射係数は `sinc(fd*0.020)*exp(2j*pi*fd*(k+0.5)*0.020)`。各20 ms区間の位相回転を解析的に平均しており、ブロック中心の位相だけを使う近似ではない。ただしコード遅延は固定する狭帯域モデルであり、周波数成分間のドップラー漏れは含まない。GPS L1で1/5/10 Hzは過剰経路長の変化率約0.190/0.951/1.903 m/sに相当し、200 ms中に省略する遅延変化は最大0.381 m。実際の森林・雨・移動受信機のモデルではない。

初回順位校正 `output/cpu-ranked-calibration/frozen_gates.json` のranked閾値 -11.266410505 を事前指定し、再校正なしで使用。受信機への入力はブロック観測値のみ。真のドップラーや信号分散は診断専用。プロトコルに全タスク・ソース・ゲートのハッシュを保存してから実行した。成功は直達波測距誤差の絶対値が10 m未満、利用不能も失敗に含める。静止反射対3動的条件の対応あり両側正確検定にBonferroni補正を適用した。

## 結果

| 反射条件 | 成功 / 128 | 2経路選択 | 利用不能 | 雑音重みの白色からのRMS偏差 |
|---|---:|---:|---:|---:|
| 反射なし | 128 | 0 | 0 | 0.03289 |
| 静止 | 87 | 96 | 0 | 0.03289 |
| 1 Hz | 125 | 127 | 0 | 0.03298 |
| 5 Hz | 128 | 0 | 0 | 0.03757 |
| 10 Hz | 128 | 0 | 0 | 0.03682 |

1 Hzは静止に対して38改善・0悪化、補正p=2.18e-11。5/10 Hzは各41改善・0悪化、補正p=2.73e-12。静止成功率の点ごと95%区間は59.1–75.9%、1 Hzは93.3–99.5%、128/128でも97.2–100%。条件間で観測を共有しているため、独立な総試行数として合算しない。反射なしの誤った2経路選択は0/128だが、その95%上限は2.84%であり、実測で1%以下を証明したわけではない。

信号変化が生むブロック間分散 / 真の雑音分散（全帯域平均）は1 Hzで0.00116、5 Hzで0.00911、10 Hzで0.00824。動的信号が雑音推定に混入することは確認できるが、平均反射そのものも変わるため、測距への影響をこの比較だけで分離できない。

特に5/10 Hzは200 msで整数周期となり、平均反射係数が理論上ゼロになる。これらの128/128成功は動く反射を追跡・除去できた証拠ではない。1 Hzでも平均反射電圧は0.8から0.748へ下がり、平均位相は約0.628 rad変わる。初期位相が同相という限定的な比較であり、動く反射が常に有利とは結論できない。校正時の静止帰無モデルの保証を任意の動的環境へ拡張しない。

次は積算の相殺点を避けたドップラーと複数の初期位相を事前固定し、同じ平均反射を持つ静止対照を追加する。平均信号の変化と雑音推定への混入を切り分ける。現段階では受信機の数値モデル・閾値を変更していない。

## 再現・検証

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_dynamic_reflection.py tests/test_noise_aware_multipath_cpu.py tests/test_ranked_path_gate_cpu.py

python experiments/run_cpu_dynamic_reflection.py
python experiments/audit_cpu_dynamic_reflection.py
python experiments/plot_cpu_dynamic_reflection.py
```

20テスト成功。位相回転の数値積分との一致、200 ms平均の解析解、条件間の同一雑音、静止信号の分散消去を検証。監査は640レコードの完全性、固定ソース・ゲート、全選択・集計の再計算、5条件の代表ケース再生成を確認した。出力は `output/cpu-dynamic-reflection/` に保存。
