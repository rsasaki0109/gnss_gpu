# 反射なし信号のドリフトを二経路と誤認するか

前回は反射あり・経路数既知で、周波数ドリフトがあっても800 msの距離成功数が低下しなかった。今回は反射を完全に除き、一定搬送波を仮定する受信処理がドリフトを架空の反射で説明していないかを、自動選択で検証する。

## 設計と校正

- PRN1、白色雑音37 reference dB-Hz、片側帯域3.6828 MHz、20 msブロック。反射は存在しない。
- 直達の初期搬送波f0は一様分布[-1,1] Hz、遅延と初期位相も従来の生成分布。共通周波数はf(t)=f0+a t、a=0/0.5/2 Hz/秒。
- 受信処理は既存 `duration_carrier_paths_cpu.py`、選択器は `calibrated_common_carrier_cpu.py` を変更せず利用。
- 200 msの閾値は既存の−24.99826377099785を保持する。新しい乱数系列だが、ゼロドリフト時の信号・雑音の生成分布と200 ms推定工程は以前の校正と同じ。
- 800 msでは独立なゼロドリフト反射なし299例（ID940000〜）から、スコア最大値を新しい閾値にする。すべての校正が完了し閾値を保存した後で評価を始める。
- 評価は別の32例（ID950000〜）を2時間×3ドリフト条件で共有し、全192推定。同じ雑音と初期状態を使い、200 msは800 msの完全一致する先頭部分。

各時間の校正は、固定したゼロドリフト生成分布における1%上側確率を、校正失敗確率 .99^299<5%で抑える。最終二経路選択はスコア閾値超過の部分集合である。**二つの時間を合わせた同時95%保証ではない**（単純な和の上界は10%未満）。ドリフトが非ゼロの分布は、どちらの校正保証にも含まれない。

## 評価の読み方

反射なしなので、二経路選択はすべて偽検出。選択されたモデルが局所ガードを通らなければ利用不能とし、別モデルへフォールバックしない。スコア超過、最終二経路選択、利用不能、距離誤差10 m未満を別々に数える。単一路を既知とした距離診断も参考として保存する。

32例は小規模な探索的検証。正確95%区間は点別であり、同時区間ではない。共有乱数による6条件を独立な192標本とは扱わず、優越性検定を行わない。結果を見て閾値を再調整しない。

## 結果

新しく凍結した800 ms閾値は **−29.838843565098603**。各欄32例。

| 観測時間 ms | ドリフト Hz/秒 | スコア超過 | 偽二経路選択 | 利用不能 | 距離誤差10 m未満 | 単一路既知の距離成功 |
|---:|---:|---:|---:|---:|---:|---:|
| 200 | 0 | 0 | 0 | 0 | 32 | 32 |
| 200 | 0.5 | 0 | 0 | 0 | 32 | 32 |
| 200 | 2 | 0 | 0 | 0 | 32 | 32 |
| 800 | 0 | 0 | 0 | 0 | 32 | 32 |
| 800 | 0.5 | 25 | 17 | 8 | 24 | 32 |
| 800 | 2 | 32 | 9 | 23 | 9 | 32 |

800 ms・0.5 Hz/秒では存在しない反射を17/32で選択し、偽二経路率の点別正確95%区間は34.74〜70.91%。800 ms・2 Hz/秒では9/32、区間13.75〜46.75%。0/32条件の同区間の上限は10.89%であり、小規模評価の0件を1%保証と取り違えない。

2 Hz/秒で偽二経路件数が0.5 Hz/秒より少なくなったことを改善と解釈してはならない。全32例のスコアが閾値を超え、うち23例は要求された二経路推定が探索境界に達して棄却されている。0.5 Hz/秒の利用不能8例もすべて探索境界である。

単一路を既知とすれば全条件32/32で距離成功していた。今回のデータでは距離推定そのものより、周波数ドリフトを表現できないモデルによる経路数の選択が問題として現れた。誤って二経路を選んでも距離が10 m未満に収まる例があるため、距離成功率だけでは偽反射検出を見落とす。

前回の「反射あり・経路数既知では800 msでも距離成功が維持された」という結果と矛盾しない。今回は自動経路選択という別の評価軸を追加し、長時間化に伴う不整合が明らかになった。200 msと800 msはそれぞれ別の適切なゼロドリフト校正を使っているが、今回の比較は長時間化の物理的効果だけを分離したものではない。

次の実装候補は、共通周波数の変化率も**単一路・二経路の両方**で推定するモデルである。二経路だけを柔軟にすると、単一路モデルの不整合を反射で説明する問題が残る。まず今回の失敗信号でモデル適合を診断し、推定工程が変わった後は全体を独立校正して未使用信号で検証する必要がある。

## 検証・再現

反射なし無雑音信号の遅延・搬送波復元、単一路としての時間構造、観測時間間の先頭一致、ドリフト条件間の共通雑音を確認した。ドリフト生成と選択規則を含めて5テストが成功。

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_drift_null_selection.py tests/test_carrier_drift_stress.py tests/test_calibrated_common_carrier_cpu.py

python -m experiments.run_cpu_drift_null_selection
python -m experiments.audit_cpu_drift_null_selection
python -m experiments.plot_cpu_drift_null_selection
```
