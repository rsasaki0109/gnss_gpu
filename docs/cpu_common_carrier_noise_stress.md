# 共通搬送波推定・自動選択の色付き雑音ストレス試験

白色雑音で校正した共通搬送波推定器と閾値を固定し、雑音の周波数分布だけを変更した。全288観測は新しい乱数IDを使い、条件間では信号と標準化雑音を対応させた探索実験である。色付き雑音に対する再校正は行わない。

## 条件

- 受信処理：`common_carrier_paths_cpu.py`、選択器：`calibrated_common_carrier_cpu.py`。
- 固定閾値：前回 `cpu-common-carrier-selection/frozen_gate.json` の **−24.99826377099785**。
- PRN1、37 reference dB-Hz、10×20 ms、片側帯域3.6828 MHz、共通残留搬送波は観測ごとに一様分布[-1,1] Hz。
- 各雑音条件で反射なし64例、反射あり32例。反射は電圧比0.8、超過遅延0.1 chip、相対Doppler+0.7 Hz、初期相対位相0。
- 雑音条件間で直達遅延、位相、共通搬送波、信号、標準化雑音を共通化。反射なしID840000〜と反射ありID850000〜は別。以前の校正・評価とも重複させない。

x=f/max|f| とすると、白色whiteは1、中央集中centerは1+9 exp(−0.5(12x)^2)、端集中edgeは1+9x^4。それぞれ全調波の算術平均が1になるよう正規化する。期待される帯域全体の雑音エネルギーは等しいが、距離推定に有効な情報量が等しいとは限らない。色付き条件では周波数に依存しない単一PSDは存在せず、reference C/N0は平均PSDを基準とする。

生成器は白色観測から信号を除いた雑音に各形状の平方根を掛け、同じ信号に加え直す。白色条件は既存生成器とビット単位で一致する。受信処理には雑音形状の真値を渡さない。

## 解釈の範囲

白色分布で得た校正保証は、中央集中・端集中の雑音分布には適用できない。本試験は記述的な探索比較で、優越性検定は行わない。集計の正確95%区間は点別であり、同時区間ではない。共有乱数を使う3条件を独立標本として合算しない。

距離成功は誤差の絶対値10 m未満で、利用不能を失敗として分母に含める。真の経路数を使う診断結果は、自動選択とは分けて保存する。

## 結果

| 雑音 | 反射なし：偽二経路 /64 | 反射なし：距離成功 /64 | 反射あり：二経路選択 /32 | 反射あり：距離成功 /32 | 反射あり：既知経路数の距離成功 /32 |
|---|---:|---:|---:|---:|---:|
| 白色 | 0 | 64 | 29 | 28 | 31 |
| 中央集中 | 0 | 64 | 32 | 32 | 32 |
| 端集中 | 0 | 64 | 31 | 29 | 30 |

全条件で利用不能0例、反射なしのスコア閾値超過も0例だった。0/64の偽二経路率に対する点別正確95%区間は **0〜5.60%**。色付き雑音の真の誤判定率が1%以下であることを示す検証規模ではない。

反射ありの距離成功を白色と対応比較すると、中央集中は4例改善・0例悪化、端集中は2例改善・1例悪化だった。成功率の点別正確95%区間は白色71.01〜96.49%、中央集中89.11〜100%、端集中74.98〜98.02%。32例の記述的な差であり、雑音条件間の優越性を主張しない。

白色では既知経路数の31成功に対して自動選択は28成功、端集中では30に対して29成功。閾値による取りこぼしがそれぞれ3例・1例残った。一方、既知経路数でも白色1例・端集中2例が失敗するため、すべての誤差をモデル選択だけで説明することはできない。

今回の合成条件では色付き雑音による大きな性能破綻は観測されなかった。ただし「中央集中の雑音は一般に有利」「任意のPSDに頑健」とは言えない。平均PSDを一定にする操作は、周波数ごとの信号対雑音比と遅延情報も変える。中央集中条件で成功数が増えた機序を、この実験だけで確定したわけではない。

次は、反射の相対Dopplerが小さい場合や位相が逆相に近い場合を、同じ受信処理と閾値のまま調べる。今回は相対Doppler+0.7 Hz・初期位相0に固定しており、経路を識別しにくい条件への保証はない。

## 検証と再現

雑音形状だけが変化すること、信号・遅延・標準化雑音の条件間一致、白色条件の完全一致、形状の平均1をテストした。自動選択・共通搬送波推定のテストと合わせて11件が成功。監査では固定ソースと閾値のハッシュ、以前の校正・評価とのID非重複、全288件の選択と集計を確認した。3雑音条件×反射の有無から各1例、計6例のフル再実行も完全一致した。

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_common_carrier_noise_stress.py tests/test_calibrated_common_carrier_cpu.py tests/test_common_carrier_paths_cpu.py
# Requires an empty output/cpu-common-carrier-noise-stress directory
python -m experiments.stress_cpu_common_carrier_noise
python -m experiments.audit_cpu_common_carrier_noise
python -m experiments.plot_cpu_common_carrier_noise
```

実験前に全タスク、ソースと元の閾値のハッシュをprotocol.jsonへ保存。成果物は `output/cpu-common-carrier-noise-stress/` の evaluation.jsonl、report.json、completion.json、audit.json、comparison.png/pdf。

この雑音は合成した独立調波雑音であり、実測フロントエンドや森林・雨の雑音モデルではない。信号は固定コード遅延の狭帯域モデルで、追尾ループ、調波間漏洩、ナビゲーションビット、複数衛星のPVTを含まない。
