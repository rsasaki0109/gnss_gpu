# 広帯域で探索境界に達した29例の診断

## 対象と目的

[帯域拡大の独立追試](cpu_drift_bandwidth_replication.md)では、片側7.37MHzの反射あり64例中29例が超過遅延パラメータの探索境界に達し、利用不能となった。今回、その29例を全て診断する。真の距離に近い推定値だったという理由だけで、利用可否ガードを外すことはしない。

これは結果を見て選んだ失敗例の事後診断である。独立標本による成功率評価や、新しい受信機の性能試験ではない。元の受信機、過去の評価結果、校正ゲートは変更しない。

## 比較条件

以前のIQと推定済み残差重みを再生成し、SHA256の一致を確認して固定する。二経路モデルは共通初期周波数と線形ドリフトを含み、帯域は7.2チップレート（片側7.3656MHz）のまま。

- 元の境界を維持：超過遅延の下限0.01chip、上限1.2chip。
- 下限を拡張：下限だけ0.001chipへ変更。最初の遅延・周波数・ドリフト・相対Dopplerの範囲は同じ。
- 両方とも、17遅延×4共通周波数×4ドリフト×5超過遅延×5相対周波数から上位24初期値を選び、以前の推定値を追加して25開始点を最適化。周波数とドリフトには以前の推定値も含め、真値は使わない。
- 最大400反復。元の解も候補に残し、明示的な設計行列と線形最小二乗による残差平方和が最小の候補を採る。最良候補が非収束なら、その事実を残す。

残差の相対改善が1e-9より大きい場合を「実質的な改善」とする基準を事前に固定する。有限の多開始点探索なので、大域最適性を証明するものではない。

## 確認する量

残差平方和、境界への到達、収束状態に加え、局所的な最初の遅延の標準偏差、テンプレート行列の条件数、成分の相殺比を記録する。相殺比は各経路の予測信号ノルムの和を、合成予測信号のノルムで割った値で、大きいほど大きな成分が打ち消し合っている。

局所標準偏差は以前と同じ射影Jacobianと9実パラメータの自由度を用いて計算する。情報行列が数値的に特異ならNoneとし、擬似逆行列で有限の値を作らない。境界解でこの数値を校正済みの信頼区間として使わない。

真値との距離誤差も診断用に記録するが、境界や不確かさのガードを無視した誤差10m未満の件数は、受信機の成功数とは呼ばない。

## 再現と検証

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_wideband_boundary.py tests/test_bandwidth_drift_paths.py
python -m experiments.diagnose_cpu_wideband_boundary
python -m experiments.audit_cpu_wideband_boundary
python -m experiments.plot_cpu_wideband_boundary
```

実験本体は空の `output/cpu-wideband-boundary` を要求する。対象29例、ソースと元データのハッシュ、探索条件を計算前に保存する。

関連テスト5件が通過。対象例の選別、両方の超過遅延下限での明示残差とコンパクト計算の一致、既存の帯域可変受信機のテストを含む。監査では29例×3状態の残差・局所情報などを再計算し、2例で探索全体を再実行する。

## 適用範囲

理想化した単一衛星、固定2経路、白色雑音、理想的な航法ビット除去、共通線形ドリフトの合成信号に限定する。雨・森林・実機RF・複数衛星測位の性能を示すものではない。

## 結果

| 指標（29例） | 同じ境界で探索を拡張 | 下限0.001chipへ拡張 |
|---|---:|---:|
| 残差の実質的改善（相対>1e-9） | 0 | 27 |
| 超過遅延が下限に到達 | 29 | 27 |
| 最良候補が非収束 | 0 | 1 |
| 局所標準偏差が0.1chip超または算出不能 | 0 | 28 |
| ガードを無視した距離誤差<10m | 29 | 29 |
| 局所標準偏差の範囲 chip | 0.0664〜0.0954 | 0.0872〜0.9961 |
| 信号成分の相殺比 | 18.2〜25.7 | 27.4〜256.3 |
| テンプレート行列の条件数 | 35.4〜37.6 | 44.8〜374.6 |

同じ境界での最大相対残差改善は6.49e-14で、事前基準1e-9を大きく下回った。この追加探索では、以前の結果を有意に改善する解は見つからなかった。有限探索のため大域最適性の証明ではない。

下限を0.001chipへ広げると、27例で事前基準を超える残差改善があった。ただし最大でも相対1.24e-7で、27例は新しい下限へ到達した。局所標準偏差は元の値の約1.20〜10.44倍となり、28例で既存の0.1chip基準を超えた。より近接した大きな成分が打ち消し合う解を許すことで、わずかな残差改善とともに推定の不確かさが増した。

例外は2例ある。ID1260031は超過遅延0.008387chipの内点へ移り、局所標準偏差0.08724chip、距離誤差+2.316mで、既存の収束・形状境界・標準偏差条件を満たす候補だった。ただし相対残差改善は7.66e-11で実質的改善基準未満。ID1260042も0.005286chipの内点へ移ったが、局所標準偏差0.15970chipで既存基準を超えた。ID1260022の最小残差候補は非収束だったため、その状態を隠さず記録した。

ガードを無視すると両比較とも全29例の距離誤差は10m未満だが、これは選択済みの合成失敗例に対して真値を使った事後集計である。ガードを外した受信機が安全だという根拠にはならず、主試験の成功数を変更しない。

## 判断

**探索境界の一律緩和は採用しない。** 大半の例は新しい境界に追随し、局所情報も悪化するため、単に初期値が少なかったり下限が高すぎたりしただけとは説明できない。1例に条件を満たす内点候補が見つかったことは記録するが、29例全体が回復したとは扱わない。

次は二経路の相殺が強い場合に、モデル内の最初の遅延がどこまで観測から識別できるかを評価する。境界にあるという理由だけを外すのではなく、異なる遅延解を許したときの損失や情報量、必要な帯域・信号強度・時間条件を整理する。新しい利用可否規則を作る場合は、診断に使っていない独立データで検証する。

## 監査結果

全29例の元観測・重み・ソース・成果物ハッシュと対象選択を確認。元の解、同境界での解、緩和後の解の計87状態で明示残差・局所情報・相殺比などを再計算し、2例では探索全体を再実行した。明示残差計算どうしの最大絶対差は約1.24e-10。局所情報の良否や残差一致は、実環境の精度保証とは区別する。
