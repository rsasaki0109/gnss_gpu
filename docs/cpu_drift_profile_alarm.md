# 距離プロファイルによる警報の独立校正

## 目的と警報指標

[前回の6例の診断](cpu_drift_delay_profile.md)から、単一路の局所標準偏差が小さくても、異なる距離の二経路解が信号を説明できることが分かった。本試験では指標を固定して、新しい反射なしデータで警報しきい値を校正し、さらに別のデータで評価する。

既存受信機が単一路を選んだ場合だけ、推定遅延から±0.05、±0.1、±0.15chipの候補と、観測から得た二経路推定遅延を調べる。[-1,1]chipへ制限し、単一路推定から10m以内の候補は除く。残差重みとプロファイル探索方法は前回のまま固定する。真の遅延や反射振幅は警報計算に渡さない。

警報スコアは `max(0, 2*Ncomplex*log(single_SSE/min_distant_two_SSE))`。最適化が収束した遠方候補だけを使う。既存受信機が二経路を選んだ場合や利用不能の場合は診断を適用せず、スコア0とする。全候補が非収束の場合もスコア0とし、別途unresolvedを記録する。スコアが大きいほど、離れた二経路候補が単一路より良い残差を持つ。

これは警報の追加であり、距離推定値を修正する機能ではない。二経路を選択した場合の危険な距離誤差も対象外であり、評価では見逃しとして数える。

## 校正と評価の分離

- 校正：独立した反射なし299例、ID1120000–1120298。
- 評価：反射なし64例（1130000–1130063）、弱い反射32例（1140000–1140031）、強い反射64例（1150000–1150063）。全群と過去試験でIDを分離。
- 800ms、PRN1、直接波基準37dBHzの白色雑音、片側3.6828MHz。共通周波数U[-1,1]Hz、ドリフトU[-2,2]Hz/s。
- 反射は電圧比0.2または0.8、超過遅延0.03chip、位相π、相対Doppler 0Hz。
- 既存の経路選択ゲートは変更しない。警報ゲートは校正スコアの最大値で、厳密に超えた場合だけ警報。評価観測を処理する前に保存する。

独立同分布の反射なしスコアについて、真の上側確率が1%を超える校正失敗確率は `0.99**299 < 0.05`。厳密な超過判定なのでスコア0等の同点は保守的になる。これは生成分布の周辺保証であり、周波数・ドリフト・信号強度の全条件で一様な保証ではない。また、反射時の危険誤差の見逃し率には保証を与えない。

警報率は全試行を分母とし、距離誤差≥10mの利用可能例について捕捉・見逃しを集計する。既存の利用不能と、新たな警報を区別する。元は誤差<10mだった例への警報も数え、警報による利用可能性の損失を確認する。

## 再現

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_drift_profile_alarm.py tests/test_drift_delay_profile.py
python -m experiments.run_cpu_drift_profile_alarm
python -m experiments.audit_cpu_drift_profile_alarm
python -m experiments.plot_cpu_drift_profile_alarm
```

実験本体は空の `output/cpu-drift-profile-alarm` を要求する。プロトコル・ソースハッシュ・校正観測・凍結ゲート・評価観測・集計を保存する。監査では全459例のスコアと選択を再集計し、校正の両端と最大スコア例、および評価4例を完全に再実行する。

## 限界

合成された単一衛星のコード距離を対象とする。理想的なコヒーレント積分、固定2経路、線形の共通ドリフトを仮定しており、RF・森林・降雨・追尾ループ・複数衛星測位は含まない。探索は有限の遅延候補と局所最適化であり、大域的なプロファイルや校正済みの距離保護レベルではない。

## 結果

警報しきい値は **15.510481468083325**。校正299例で候補単位の非収束は10点、評価160例では3点だった。全候補が非収束となるunresolved観測は0例だった。

| 評価条件 | 警報 / 全試行 | 元から利用不能 | 利用可能だが誤差≥10m | 警報で捕捉 | 見逃し | 誤差<10mへの警報 |
|---|---:|---:|---:|---:|---:|---:|
| 反射なし | 0/64 | 0 | 0 | 0 | 0 | 0 |
| 弱い反射 | 0/32 | 0 | 0 | 0 | 0 | 0 |
| 強い反射 | 17/64 | 27 | 28 | 17 | 11 | 0 |

反射なしの評価0/64の正確95%区間は0–5.60%。これは「真の誤警報率が0」の証明ではない。校正299例に基づく1%・95%の周辺保証とは別の評価統計である。弱い反射の警報0/32も、他の弱い反射条件まで無警報と保証しない。

強い反射の選択内訳は、単一路22例、二経路15例、利用不能27例。単一路22例はすべて誤差≥10mで、17例に警報、5例を見逃した。二経路15例のうち誤差≥10mは6例あり、本診断の対象外なので全て見逃しに含めた。合計の捕捉は17/28（60.7%、点ごとの正確95%区間40.6–78.5%）であり、完全な安全性指標には至っていない。

強い反射で元から誤差<10mだったのは9/64例（正確95%区間6.6–25.0%）。警報後も成功は9例のままで、距離精度は改善していない。警報を出した観測を保留すると、元の利用不能27例に17例が加わって44/64例が使えなくなり、残り20例のうち11例には誤差≥10mが残る。

前回の独立標本では同じ強い反射条件で25/64例が誤差<10mだった。今回9/64例へ下がったことは、基礎受信機の性能評価も追加標本で検証すべき点である。前回と今回を選別して良い方だけを報告せず、別々の結果として保存する。

## 検証と次の課題

関連テスト10件が通過。監査で全459例の生成ID、既存の経路選択、候補遅延、警報スコア、校正ゲート、評価の警報と集計、ソース・成果物ハッシュを確認した。校正の最初・最後・最大スコアの3例と、評価4例の計7例を完全再実行した。

次は、まず同じ強反射条件で基礎受信機の成功率が変動した点を、追加の事前固定した標本で調べる。そのうえで、単一路に対する見逃し5例と対象外の二経路失敗6例を分けて原因を診断する。本評価を見て警報ゲートを下げることはしない。二経路推定にも診断を広げる場合は、別の校正・評価データで誤警報と利用可能性を改めて検証する。
