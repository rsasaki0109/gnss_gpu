# 直接波優勢の振幅制約を持つ二経路推定

## 目的

[両モデルに適用した曖昧さ指標](cpu_drift_ambiguity.md)では、反射なしの信号にも弱い先行経路を追加でき、警報が機能しなかった。今回は `|反射の複素振幅| <= |最初の経路の複素振幅|` を課した推定器を実装する。この仮定が成り立つ電圧比0.8と、意図的に仮定を破る電圧比1.2を比較する。

## 振幅最適化

固定された経路形状について、まず通常の複素最小二乗解を求める。その解が制約を満たす場合は変更しない。満たさない場合、最適解は両経路の振幅が等しい境界にある。振幅を `a*[1, exp(i*theta)]` と表し、共通の複素スケールaを消去すると、位相thetaについて一次の三角多項式どうしの比を最大化する問題になる。

その導関数は `P*sin(theta)+Q*cos(theta)+R=0` となるため、停留位相を解析的に求めて候補を比較する。振幅最適化に位相グリッドを使用しない。Gram行列が正定値の場合の固定形状での振幅解法であり、経路形状まで含む大域最適性を保証するものではない。

形状の目的関数は既存のキャッシュ付きドリフトモデルから分離して実装した。振幅制約は形状パラメータに依存しないため、滑らかな点では最適振幅を用いた包絡線勾配を使える。制約の切替点や同値解の非滑らかさには注意が必要となる。既存の無制約受信機のソースは変更していない。

## 比較設計

- 新しい16乱数ID（1220000–1220015）を、反射電圧比0.8・1.2で共用した計32観測。同じ直接波・周波数・ドリフト・雑音を用いる。
- 超過遅延0.03chip、位相π、相対Doppler 0Hz。800ms、PRN1、白色雑音、直接波基準37dBHz、片側帯域3.6828MHz。
- 両方式に同じ、既存の無制約受信機から推定した残差重みを渡す。制約付き推定では既存の粗探索を使い、元の二経路推定値からの初期化も追加する。
- **経路数2を既知とした試験**であり、反射検出や警報の比較ではない。元の経路選択ゲートを新推定器へ流用しない。
- 両方式とも、最適化が収束し、形状パラメータが探索境界から1e-4以上離れ、距離誤差が10m未満なら成功と数える。
- 制約付き境界での標準偏差を未校正のまま使わないため、今回は両方式とも局所標準偏差のガードを適用しない。以前の「利用可能率」と直接比較しない。
- 振幅制約の境界到達は記録するが、それだけで失敗とは判定しない。これは精度や安全性の保証ではない。

乱数・実装ハッシュ・比較条件を実行前に保存。各電圧比の点ごとの正確区間は探索的であり、16個の共通乱数を独立32個としてプールしない。

## 再現

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_dominant_drift_paths.py tests/test_cached_drift_paths.py
python -m experiments.run_cpu_dominant_path_pilot
python -m experiments.audit_cpu_dominant_path_pilot
python -m experiments.plot_cpu_dominant_path_pilot
```

実験本体は空の `output/cpu-dominant-path-pilot` を要求する。最初の実行は結果保存時のNumPy真偽値のJSON変換で停止した。失敗したプロトコルと修正前ソースを `output/cpu-dominant-path-pilot-aborted-json` に保存し、真偽値をPythonのboolに揃える修正だけを行って同じ試験を再実行した。失敗実行には評価行が保存されていない。

## 適用範囲

直接波が反射より強いことは、森林・遮蔽環境で一般に保証できない。電圧比1.2はその仮定違反の簡単な例であり、実環境の遮蔽モデル全体を表すものではない。単一衛星の固定した合成2経路でのコード距離推定に限定され、実機や複数衛星測位の精度を主張しない。

## 結果

| 真の反射/直接波電圧比 | 無制約：成功 | 制約付き：成功 | 無制約：形状境界等で対象外 | 制約付き：同対象外 | 振幅制約の境界に達した最終解 |
|---|---:|---:|---:|---:|---:|
| 0.8（仮定成立） | 6/16 | 6/16 | 4/16 | 4/16 | 0/16 |
| 1.2（仮定違反） | 0/16 | 0/16 | 5/16 | 7/16 | 0/16 |

0.8条件では、成功への回復・成功から失敗への変化はともに0例。制約付きの推定電圧比は0.222〜0.934で、最終解は全て振幅制約の内側だった。無制約との差は距離で最大約0.000129mにとどまった。誤った距離解も「最初の経路が強い」という制約を満たすため、この制約だけでは排除できない。

1.2条件では、制約付き推定の最終電圧比が0.149〜0.908となった。真の振幅関係を禁止すると、必ず振幅比1の境界に留まるわけではなく、別の距離・振幅を持つ内側の解へ移る。制約付きの距離誤差は全例+28.17〜+46.32mで、無制約は−19.29〜+46.32mだった。対象外の総数は5から7へ増えたが、対応する内訳は3例が境界へ移り、1例が境界から内側へ移ったもので、いずれも成功にはならなかった。

両群とも16例の小規模試験である。0.8条件の6/16の点ごとの正確95%区間は15.2〜64.6%。1.2条件の0/16も、母集団の成功率が厳密に0という意味ではない。仮定違反時に制約が無害だとはいえない一方、ここでの結果をあらゆる遮蔽・反射条件に一般化もしない。

## 検証結果と判断

関連テスト8件が通過。振幅解は独立したSLSQP制約最適化と比較し、制約が有効な場合・無効な場合の解析勾配を数値微分で検証した。JSON変換不具合の回帰テストも追加した。

監査では32例すべての振幅制約、明示残差、真値からの距離誤差、収束・形状境界による成功判定、ソース・成果物ハッシュを照合した。16組の雑音一致を確認し、各振幅条件から1例ずつ計2例を完全再実行した。

今回の制約付き推定は比較用実装として保存するが、既存受信機の既定動作へは採用しない。警報ゲートや局所標準偏差も再利用しない。単純な振幅順序では、今回の強い近接逆位相反射の距離誤差を改善できなかった。

次は同じ合成信号条件で、観測に含まれる距離情報そのものを増やす方向を比較する。例えば帯域を拡大すると近接反射を分離しやすくなる可能性があるが、雑音帯域・信号電力・計算量を揃えた比較が必要となる。今回の失敗例に合わせて振幅上限をさらに厳しく調整することはしない。
