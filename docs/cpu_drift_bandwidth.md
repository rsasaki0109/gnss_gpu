# 帯域拡大による近接反射の距離推定比較

## 目的と設計

振幅の大小関係を制約するだけでは近接する逆位相反射の誤差を改善できなかったため、今回は観測に含まれる高周波成分を増やす。片側帯域をチップレートの1.8倍・3.6倍・7.2倍（約1.84・3.68・7.37MHz）で比較する。ここで「帯域」は片側カットオフであり、実数サンプリングのナイキスト条件などで使う両側幅とは異なる。

未使用16乱数ID（1240000–1240015）を3帯域で共有する。800ms、PRN1、反射電圧比0.8、超過遅延0.03chip（約8.8m）、相対位相π、相対Doppler 0Hz。初期共通周波数とドリフトは以前と同じ分布で生成する。

最も広い帯域の信号・雑音を生成し、狭い帯域は周波数成分の部分集合として切り出す。重なる成分のIQと信号はビット単位で一致する。直接波のフィルタ前C/N0を37dBHz、各周波数成分の雑音分散を `1/(10**3.7*0.020)` に固定する。帯域内の信号電力を再正規化しない。帯域を広げれば信号成分も総雑音も増えるため、総雑音電力を揃えた比較ではない。

## 受信機と評価

`python/gnss_gpu/bandwidth_drift_paths_cpu.py` に、既存のキャッシュ付き共通ドリフト受信機を帯域可変にしたコピーを実装した。既存の凍結ソースは変更しない。探索範囲・初期値探索・局所情報ガード・残差重みの101周波数ビン平滑化は同じまま。周波数ビン幅は全帯域で1kHzなので、平滑化の物理的な周波数幅も同じである。

**二経路が存在することを既知とした推定比較**であり、反射検出や警報の評価ではない。狭帯域用に校正したゲートを広帯域へ流用しない。二経路フィットが既存の局所利用可否ガードを通り、距離誤差が10m未満なら成功と数える。利用不能も全試行の成功率分母に残す。

## 結果

| 片側帯域 MHz | 周波数成分数 | 残る直接波電力 | 成功 / 16 | 利用不能 / 16 | 3.68MHz比の回復 / 損失 |
|---|---:|---:|---:|---:|---:|
| 1.8414 | 3,683 | 94.85% | 0 | 7 | 0 / 2 |
| 3.6828 | 7,365 | 97.25% | 2 | 10 | — |
| 7.3656 | 14,731 | 98.56% | 11 | 5 | 10 / 1 |

約3.68MHzから約7.37MHzへの拡大で成功数は2/16から11/16へ増えた。ただし16例中10例が成功へ変わり、1例が失敗へ変わった。全例で単調に改善したわけではない。最も広い帯域の5失敗例は全て利用不能だった。

点ごとの正確95%区間は3.68MHzの2/16で1.55〜38.35%、7.37MHzの11/16で41.34〜88.98%。共通乱数を使う対応のある小規模試験であり、48個の独立標本としてプールしない。複数帯域の同時保証や、実環境での成功率を示すものではない。

信号の帯域内電力増加は3.68→7.37MHzで約1.31パーセントポイントにとどまる一方、遅延の変化に敏感な高周波成分が追加される。この結果は近接反射の分離に帯域が有用である可能性を示すが、情報量・局所探索・重み推定などの寄与を個別に分離した証明ではない。

広帯域では複素観測数が294,600から589,240にほぼ倍増し、理論上の1ブロック当たり総雑音エネルギーも73.48から146.96へ増える。雑音の単位は直接波フィルタ前振幅を1とするスペクトル観測の正規化単位であり、電力計のワット値ではない。

## 再現と検証

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_bandwidth_drift_paths.py
python -m experiments.run_cpu_drift_bandwidth
python -m experiments.audit_cpu_drift_bandwidth
python -m experiments.plot_cpu_drift_bandwidth
```

実験本体は空の `output/cpu-drift-bandwidth` を要求する。プロトコルとソースハッシュを観測生成前に保存する。デフォルト3.6倍帯域の全推定パイプラインが従来実装と完全一致すること、共通帯域のIQと信号の完全一致、広帯域での勾配と明示残差をテストし、3件とも通過した。

監査では全48観測の生成ハッシュ・成功判定・集計、32組の狭帯域/広帯域の完全一致、過去試験とのID非重複、逐次計算時間6記録を確認し、各帯域から1例ずつ完全再実行して全て一致した。

## 限界と次の段階

矩形フィルタの周期定常状態・白色雑音・理想的な航法ビット除去・固定2経路を仮定した単一衛星のコード距離試験。実機RFの帯域、量子化、アンテナ、森林や降雨、追尾ループ、複数衛星測位は含めていない。

広帯域化を既定動作へ即座に採用する段階ではない。次は独立した乱数で今回の改善を再検証し、反射がない条件でも誤検出や利用不能が増えないか調べる。モデル選択に組み込む場合は帯域ごとの独立校正が必要になる。

## CPU計算時間

独立評価の後に、各帯域で1回ウォームアップし、最初の2観測について全4フィットの推定パイプラインを逐次計測した。帯域の順序は1観測目が狭→広、2観測目が広→狭。観測生成と結果照合は計測外で、BLASは1スレッド。

各帯域2測定の中央値は、1.84MHzで1.45秒、3.68MHzで2.50秒、7.37MHzで4.36秒。広帯域は基準帯域の約1.74倍だった。2例のみの記述的な計測であり、一般的な速度比やリアルタイム動作を保証しない。観測時間は0.8秒なので、今回の逐次推定はリアルタイム処理を満たしていない。
