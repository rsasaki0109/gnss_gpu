# ドリフト推定器の反射位相・相対Doppler感度

これまでのドリフト推定器の校正後評価は、反射の相対Doppler+0.1 Hz・初期逆位相に固定していた。今回は高速化版の受信処理と閾値を固定し、反射の位相と周波数差を広げて感度を調べる。

## 実験条件

- 受信処理：`cached_drift_carrier_paths_cpu.py`。前回の全395観測で元実装との完全一致を確認済み。
- 判定閾値：`cpu-drift-selection/frozen_gate.json` の **−27.762974167383057**。変更・再校正しない。
- 800 ms、PRN1、白色雑音37 reference dB-Hz、片側帯域3.6828 MHz。
- 共通周波数変化率は一様分布[-2,2] Hz/秒、初期共通周波数は独立の一様分布[-1,1] Hz。
- 反射電圧比0.8、超過遅延0.1 chip。相対Doppler0/0.1/0.7 Hz × 初期相対位相0/90/180度、各16例。
- 全9反射条件で同じ16乱数ID1030000〜を使い、共通ドリフト・周波数・遅延・初期位相・加算雑音を対応させる。別の反射なし32例はID1020000〜。

生成器は元の+0.1 Hz・180度条件をビット単位で再現する。ほかの条件では同じ加算雑音を維持して信号だけを変える。両経路の共通ドリフトを各20 ms区間内で積分し、反射に相対Dopplerと初期位相を加える。非ゼロの相対Dopplerでは位相差が時間とともに変わる。

実験前に全タスク、全ソースと閾値のハッシュ、過去の高速化一致確認のハッシュを保存。新しい観測の全10条件から各1例を元の低速実装でも再実行し、高速化版との完全一致を追加確認する。

## 解釈の範囲

距離成功は誤差の絶対値10 m未満で、利用不能を失敗として含める。経路数を既知とした推定は参考診断として別に集計する。真の経路数を自動選択には渡さない。

各条件16例は共有乱数による対応標本であり、反射条件を独立な144例として合算しない。探索的な記述比較で有意差検定を行わない。正確95%区間は点別で同時区間ではない。新しい32例の反射なし確認も、単独で1%誤判定率を認証できる規模ではない。

過去の200 msや別モデルの結果とは観測時間・推定モデル・校正・乱数が異なるため、本実験からそれらの因果的な優越性を主張しない。

## 結果

反射あり各16例。距離成功は誤差10 m未満。

| 相対Doppler Hz | 初期位相 度 | 二経路選択 | 利用不能 | 距離成功 |
|---:|---:|---:|---:|---:|
| 0 | 0 | 16 | 0 | 16 |
| 0 | 90 | 16 | 0 | 16 |
| 0 | 180 | 16 | 0 | 15 |
| 0.1 | 0 | 16 | 0 | 16 |
| 0.1 | 90 | 16 | 0 | 16 |
| 0.1 | 180 | 16 | 0 | 16 |
| 0.7 | 0 | 16 | 0 | 16 |
| 0.7 | 90 | 16 | 0 | 16 |
| 0.7 | 180 | 16 | 0 | 16 |

反射なしは偽二経路0/32、利用不能0/32、距離成功32/32。誤選択率の点別正確95%上限は10.89%。16/16の距離成功条件でも成功率の点別正確95%下限は約79.41%であり、万能な頑健性を示したものではない。

今回の反射条件では全スコアが閾値を超え、既知経路数の距離診断と自動選択の成功分類は全例で同じだった。相対Doppler0 Hz・逆位相に残った1例は、検出の取りこぼしではなく、二経路推定が返した距離の誤差だった。

該当例は **replica 1030005**。真の共通ドリフト+1.61763 Hz/秒、初期搬送波−0.94811 Hz。推定は収束し、スコア+413.05で二経路を選んだが、距離誤差は **+12.20 m**。超過遅延は真値0.1 chipに対して0.01631 chipと推定された。局所標準偏差0.07862 chipは0.1 chipのガード以下だが、局所ガードは実際の距離誤差10 m未満を保証しない。

これまで固定していた初期逆位相・相対Doppler0.1 Hzの外でも、今回の新規16例では多くの条件で距離推定が成立した。ただし電圧比0.8・超過遅延0.1 chipは固定のまま。次はより近接した反射や振幅比を変え、どこまで経路を識別できるかを同じ閾値のまま調べるのが候補になる。今回の1例だけに合わせてガードや探索条件を調整することはしていない。
