# 共通ドリフト受信機の距離プロファイル損失

[局所不確かさの検証](cpu_drift_uncertainty.md)で、近接する強い逆位相反射があると、単一路の局所標準偏差が距離誤差を過小に表すことが分かった。今回は、最初の経路の遅延を固定し、共通周波数・ドリフト・反射の距離差と相対周波数を再最適化する診断機能を実装した。

## 実装と固定条件

`python/gnss_gpu/drift_delay_profile_cpu.py` は単一路・二経路の両方について、複素振幅を変数消去し、固定した遅延以外をL-BFGS-Bで最適化する。勾配は元の解析勾配の対応成分を使用する。元の推定器や反射検出ゲートは変更していない。

観測から推定した残差重みを全点・両モデルで固定する。遅延点は単一路推定値±0.15chip（約±44m）の等間隔25点に、観測から得た単一路・二経路の推定遅延を追加し、[-1,1]chipへ制限する。真値は探索・初期値に使わない。元の推定値と固定した補助値から初期値候補を作り、損失が小さい4候補を最適化する。境界への到達と非収束は記録し、境界解を自動的に捨てない。

各点の損失は明示的な残差ベクトルから再計算する。図の縦軸は `2*Ncomplex*log(SSE/reference)`。referenceは元の両推定値と全プロファイル点の最小SSEを共通に使う。モデルの自由度ペナルティを含まないため、これで元のモデル選択を置き換えてはいけない。

有限の初期値による局所最適化なので、真の大域的プロファイル損失の上界である。離散点の間も保証しない。残差重みの推定誤差、モデル選択、経路振幅ゼロでの非正則性があり、通常のχ²しきい値による信頼区間や保護レベルとは解釈しない。

## 診断パネル

前回の128例から、各振幅群で単一路を選択したものをID順に2例ずつ選んだ。強い反射は1100012と1100019、弱い反射は1090000と1090001、反射なしは1080000と1080001。結果を確認する前にプロトコルへ保存したが、これは過去の選択結果を使う事後的な6例の診断であり、独立追試や母集団の性能評価ではない。

| 条件・ID | 元の距離誤差 m | 局所区間半幅 m | 元の推定から10m超離れた二経路点の最小相対損失 |
|---|---:|---:|---:|
| 反射なし 1080000 | −0.56 | 1.67 | 4.70 |
| 反射なし 1080001 | −0.39 | 1.67 | 5.26 |
| 弱い反射 1090000 | −1.20 | 2.06 | 7.25 |
| 弱い反射 1090001 | −1.38 | 2.06 | 5.26 |
| 強い反射 1100012 | −22.47 | 7.21 | 約0 |
| 強い反射 1100019 | −18.06 | 7.63 | 0 |

強い反射2例では、局所区間の外にある二経路候補が単一路より小さい残差を持つことを確認した。ただし元の反射検出器は、パラメータを増やすことへのペナルティと校正ゲートも使うため、残差の改善だけでは二経路を選択しない。

反射なし・弱い反射でも、早い側に広い二経路損失の平坦部分がある。二経路モデルでは、最初の経路の振幅を小さくし、後の経路に主信号を説明させることが可能である。従って無制約な二経路モデルの距離幅を安全性の指標に直結させると、反射のない観測まで曖昧と判定し得る。本試験の曲線だけから警報しきい値を決めない。

![遅延プロファイル](../output/cpu-drift-delay-profile/comparison.png)

全312点で最適化は収束。各例の境界到達点は9〜14点あり、正則な局所近似を一律に適用できない。コンパクトな損失計算と明示残差の最大絶対差は約1.35e-10だった。

## 検証と再現

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_drift_delay_profile.py tests/test_drift_uncertainty.py tests/test_cached_drift_paths.py
python -m experiments.run_cpu_drift_delay_profile
python -m experiments.audit_cpu_drift_delay_profile
python -m experiments.plot_cpu_drift_delay_profile
```

関連テスト8件が通過。監査ではプロトコル・全ソース・以前の観測・成果物のハッシュ、選択した6例、全遅延グリッド、集計を確認。さらに全312点の残差をキャッシュ導入前の実装で再計算し、相対損失を照合した。これは最適化の大域性の証明ではない。実験本体は空の `output/cpu-drift-delay-profile` を要求する。

## 次の検証

次は、この曲線から作る曖昧さ指標の候補を固定し、未使用の反射なしデータで誤警報を校正し、別の反射データで危険な距離誤差の見逃しを評価する。最初の経路の振幅に制約を入れる場合は、直接波が弱い環境を除外する物理的仮定になるため、制約の妥当性と破れた場合を併せて検証する。

対象は合成された単一衛星のコード距離。森林・降雨・実機・複数衛星測位での性能を示す結果ではない。
