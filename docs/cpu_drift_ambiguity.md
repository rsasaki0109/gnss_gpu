# 両方の経路モデルに適用する距離曖昧さ指標

## 目的

[以前の警報](cpu_drift_profile_alarm.md)は単一路を選んだ場合にしか適用せず、二経路推定の距離誤差を見逃した。[全11例の診断](cpu_drift_alarm_misses.md)では、二経路を選んでいても真値側に低い損失の候補が残っていた。今回は選択モデルによらず、離れた遅延の二経路候補と最良の既知候補との損失差を調べる。

元の距離推定器と経路選択ゲートは固定し、新しい指標を追加診断として評価する。距離値を修正する実装ではない。

## 指標と探索

単一路または二経路が利用可能として選択された観測で、選択遅延から±0.035、±0.05、±0.1、±0.15chipの点と、観測から得た両モデルの推定遅延を候補にする。[-1,1]chipに制限し、選択遅延から10m以内の候補は除く。最も近い固定オフセット0.035chipは約10.26m。これは連続した全遅延を調べるものではない。

固定した残差重みで各候補の二経路モデルを最適化する。収束した遠方候補の最小SSEをD、元の単一路・二経路フィットおよび収束した遠方候補の最小SSEをRとして、スコアを `1 / (1 + max(0, 2*Ncomplex*log(D/R)))` とする。値が1に近いほど、離れた距離でも最良の既知解に近い損失となる。これは確率や事後確率ではない。

元から利用不能の観測や、遠方候補が全て非収束だった観測はスコア0とし、後者はunresolvedとして別集計する。数値的に僅かな改善があってもスコアの最大値は1となる。校正ゲートが1に達した場合は、厳密超過の警報は出せなくなる。この場合も事後的に同点判定や指標を変更しない。

## 事前固定した検証

- 校正：未使用の反射なし299例、ID1170000–1170298。
- 評価：反射なし64例（1180000–1180063）、弱い反射32例（1190000–1190031）、強い反射64例（1200000–1200063）。全群と過去試験でID非重複。
- 800ms、PRN1、直接波基準37dBHzの白色雑音、片側帯域3.6828MHz。共通周波数U[-1,1]Hz、ドリフトU[-2,2]Hz/s。
- 反射の電圧比0.2または0.8、超過遅延0.03chip、位相π、相対Doppler 0Hz。
- 校正299例の最大値を警報ゲートとし、厳密に超える場合のみ警報。評価処理の前にゲートを保存。

生成分布が独立同分布という条件で、反射なしの周辺誤警報率が1%を超える校正失敗確率は `0.99**299 < 0.05`。同点は厳密超過で保守的に扱う。保証は反射のある条件での見逃し率、距離誤差、あるいは全ての周波数・雑音条件を一様に覆うものではない。

## 再現と制限

```bash

pytest -q tests/test_drift_ambiguity.py tests/test_drift_delay_profile.py tests/test_drift_profile_alarm.py
python -m experiments.run_cpu_drift_ambiguity
python -m experiments.audit_cpu_drift_ambiguity
python -m experiments.plot_cpu_drift_ambiguity
```

空の `output/cpu-drift-ambiguity` にプロトコル、ソースハッシュ、校正・評価の全観測結果、ゲート、集計を保存する。元の観測や校正は上書きしない。

単一衛星の理想化した合成信号のコード距離診断であり、森林・降雨・実機RF・追尾ループ・複数衛星測位での安全性を示さない。有限の候補と局所探索しか使っておらず、連続遅延での大域最適性や距離保護レベルを保証しない。

## 次に検証すべき仮定

反射なしの観測を二経路で説明するとき、最初の経路の振幅を非常に小さくし、後ろの経路に主信号を担当させられる。自由な複素振幅を持つ二経路モデルでは、最初の経路の遅延が観測から決めにくくなる。この場合、局所探索を増やすだけで距離の識別可能性が回復するとは限らない。

「直接波が反射波より強い」という制約を導入すれば、この自由度を抑えられる可能性がある。ただし森林や遮蔽環境では直接波が弱くなるため、一般的な仮定としては使えない。次の候補は、条件を満たすLOSシナリオでの制約付き推定と、その仮定が破れるシナリオを対にした検証である。今回の結果を見て無条件に制約を追加したり、警報ゲートを下げたりしない。

## 校正で判明した飽和

校正299例のうち28例（9.4%）がスコア上限1に達した。凍結ゲートは **1.0**。定義上スコアは1以下で、厳密超過で警報を出すため、このゲートでは警報を出せない。反射なしの誤警報率を抑える保証は満たせても、危険な距離誤差を検出する用途では機能しない。

全28例で、最小損失となった遠方二経路候補を再構成し、複素振幅を線形最小二乗で求めた。先行経路/後続経路の電圧比は0.0323〜0.7107で、全例で先行経路が弱く、18例は0.1未満だった。先行経路の位置は真の直接波より9.33〜45.61m手前、後続経路の位置誤差は−7.55〜+3.69mだった。

反射なしなのに弱い先行経路を追加し、後続経路で主信号を説明できることが、広い遅延曖昧さの具体例として確認された。これは28例での事後的な再構成であり、振幅制約を入れたら必ず正解するという証明ではない。振幅や真の位置はこの診断にのみ使用し、凍結した警報の再調整には使っていない。

校正では候補単位で6点が非収束だったが、全候補が非収束のunresolved観測は0例だった。

## 独立評価と判断

| 条件 | 警報 / 全試行 | 元から利用不能 | 利用可能な誤差≥10m | 捕捉 / 見逃し | 距離誤差<10m |
|---|---:|---:|---:|---:|---:|
| 反射なし | 0/64 | 0 | 0 | 0 / 0 | 64/64 |
| 弱い反射 | 0/32 | 0 | 0 | 0 / 0 | 32/32 |
| 強い反射 | 0/64 | 27 | 29 | 0 / 29 | 8/64 |

強い反射では、単一路を選んだ24例すべてが誤差≥10m。二経路を選んだ13例のうち8例は誤差<10m、5例が誤差≥10mだった。新しい診断は両方の選択モデルに適用したが、ゲートが上限に達したため29例全てを見逃した。

この結果は単に小標本で警報が偶然出なかったことではない。スコア上限1に対してゲート1、判定が厳密超過なので、どの入力にも警報を出せない構造になっている。評価での誤警報0を検出性能の改善とは解釈しない。

評価で候補単位の非収束は4点、unresolved観測は0例。校正と評価で同じ有限探索を使用しているが、大域最適性を保証しない。本試験の失敗は「曖昧さを警報へ変換する今回の指標と校正法」の失敗であり、GNSSで距離曖昧さを評価する全方式が不可能という結論ではない。

**本指標は警報として採用しない。** 以前の単一路警報や元の経路選択器は変更していない。反射条件の異なるデータで旧方式と直接比較した試験でもないため、前回との捕捉率の差を対応のある改善・悪化検定として扱わない。
