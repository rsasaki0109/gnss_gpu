# 広帯域受信機のC/N₀感度

## 目的と固定条件

[広帯域の境界診断](cpu_wideband_boundary.md)では、探索範囲を広げるだけでは近接反射の曖昧さを解消できず、多くの例で局所標準偏差が悪化した。今回は推定器と帯域を固定し、信号に対する雑音の強さを減らしたときに、境界への到達と距離誤差が変わるか調べる。

片側帯域7.3656MHz、800ms、PRN1、共通線形ドリフトを固定した受信機を使用する。反射ありは電圧比0.8、超過遅延0.03chip、位相π、相対Doppler 0Hz。初期周波数・ドリフト・遅延・位相は前試験と同じ生成分布で、未使用の乱数IDを用いる。

- 反射あり32組（ID1290000–1290031）、反射なし16組（1280000–1280015）。
- 各組を直接波のフィルタ前C/N₀=37・43・49dB-Hzで評価し、計144観測とする。
- 信号波形と標準化した雑音は同じ。37dB-Hzの雑音振幅に `10**((37-CN0)/20)` を掛ける。43dB-Hzで雑音電力は約1/3.98、49dB-Hzでは約1/15.85になる。
- 受信機、探索境界、初期値探索、残差重み推定方法、局所ガード、積分時間は変更しない。
- 37dB-Hzは既存の信号生成結果とビット単位で一致する。

これは正規化した信号に対して雑音を減らす合成実験であり、衛星の送信電力を操作したり、アンテナ利得や実機雑音をモデル化したりする実験ではない。C/N₀は反射で相殺された後の合成信号強度ではなく、直接波基準である。

## 評価方法

経路数を既知として、反射ありでは二経路フィット、反射なしでは単一路フィットの距離を評価する。パラメータ探索には真の遅延や振幅を渡さない。利用可能と判定され、距離誤差が10m未満なら成功とする。利用不能も全試行の分母に残す。

主比較は反射あり32組の37対49dB-Hzで、両側正確McNemar検定（不一致組の二項検定）を1つだけ行う。有意水準0.05。43dB-Hzと反射なしの結果は記述的に報告し、結果を見て主比較を変更しない。各セルの区間は点ごとのClopper–Pearson 95%区間である。共通乱数による対応があるため、各レベルを独立標本としてプールしない。

既存のモデル選択・警報ゲートは使わない。反射なしの成功率は反射の誤検出率ではない。異なるC/N₀で自動モデル選択するには、その分布に対応する独立校正が必要となる。

## 再現と監査

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_wideband_cn0.py tests/test_drift_bandwidth_replication.py tests/test_bandwidth_drift_paths.py
python -m experiments.run_cpu_wideband_cn0
python -m experiments.audit_cpu_wideband_cn0
python -m experiments.plot_cpu_wideband_cn0
```

実験本体は空の `output/cpu-wideband-cn0` を要求する。全タスクとソースハッシュを事前保存し、観測ハッシュ・重みハッシュ・全フィット・判定を保存する。

関連テスト7件が通過。37dB-Hzで既存生成器と一致すること、全レベルで信号が同一で雑音振幅・電力が所定の比率となること、既存の帯域受信機と対応検定を確認した。

監査では全144観測の信号・雑音スケーリング、成功判定、過去ID非重複、ソース・成果物ハッシュを確認し、各条件1例ずつ計6例を完全再実行する。主比較のp値も二項係数の和から再計算する。

## 限界

白色雑音、固定2経路、理想的な航法ビット除去、単一衛星のコード距離に限定する。森林・雨・RF・量子化・追尾ループ・複数衛星測位の実用精度は検証していない。局所的な標準偏差のガードも安全性の保証ではなく、高C/N₀なら常に安全という結論にはしない。

## 結果

| 直接波C/N₀ | 反射あり：成功 | 利用不能 | 利用可能だが誤差≥10m | 反射なし：成功 |
|---|---:|---:|---:|---:|
| 37dB-Hz | 20/32 | 12 | 0 | 16/16 |
| 43dB-Hz | 23/32 | 9 | 0 | 16/16 |
| 49dB-Hz | 27/32 | 5 | 0 | 16/16 |

反射ありの利用不能理由は全レベルで探索境界だった。最適化の非収束はなかった。反射なしは各レベルとも全16例で成功したが、正確95%区間は79.4〜100%であり、失敗率が0という証明ではない。

主比較の37→49dB-Hzでは、32組中7組が回復、悪化0組、両方成功20組、両方失敗5組。成功率差は+21.875パーセントポイント、事前指定した両側正確検定は **p=0.015625** で、有意水準0.05を下回った。この固定した合成信号条件・既知経路数・既存ガードの下では、雑音低下による成功率の改善を確認した。

反射ありの点ごとの正確95%区間は、37dB-Hzの20/32で43.7〜78.9%、43dB-Hzの23/32で53.3〜86.3%、49dB-Hzの27/32で67.2〜94.7%。43dB-Hzには別の有意差検定を追加していない。前回の帯域追試や境界診断との結果を合算していない。

## 判断と次の課題

境界を緩めるだけでは不確かさが悪化した一方、同じ境界と受信機のまま雑音を減らすと12例の利用不能が5例へ減った。今回の近接逆位相反射では、信号に含まれる距離情報と雑音の比が利用可能性を制限していることと整合する結果である。ただし、局所探索と重み推定の寄与を個別に切り分けた証明ではない。

49dB-Hzでも5例は利用不能のままであり、一般的な安全性を保証しない。C/N₀の向上は受信機ソフトだけで任意に実現できるものでもない。この結果を理由に、既存の利用可否ガードや警報ゲートを変更しない。

次は今回固定していた反射位相・相対Dopplerなどを変え、同じ帯域とC/N₀でこの傾向がどこまで続くかを確認する。実用的な自動経路選択を評価する際は、経路数既知の今回の結果とは分け、独立したnull校正を用いる。

## 監査結果

関連テスト7件、全144観測の信号・雑音スケーリングと生成ハッシュ、全判定・集計、過去ID非重複、ソース・成果物ハッシュを確認した。主比較のp値を独立計算し、6条件それぞれの完全再実行も一致した。結果の生データと監査記録は `output/cpu-wideband-cn0` に保存する。
