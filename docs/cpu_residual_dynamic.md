# 動的信号残差による雑音推定と経路推定の重み付け

帯域中央に雑音が偏る場合の誤った2経路選択に対処するため、動的信号モデルの残差から周波数ごとの雑音強度を推定し、重み付けして再推定する実装を追加した。旧推定器・旧校正結果は固定して保存し、新しい処理全体を別データで校正する。

## 推定処理

新規モジュール `python/gnss_gpu/residual_dynamic_paths_cpu.py` は以下を1回ずつ実行する。

1. 既存の等重み動的2経路モデルで初期推定。
2. 推定した遅延・ドップラーを使い、元の全ブロック観測に複素振幅を最小二乗で再適合し、動的信号を差し引く。
3. 残差の二乗振幅を10ブロックで平均し、101周波数成分の移動平均で平滑化。帯域端は実際の成分数で割り、全帯域平均の1e-6倍を下限として、平均1の相対雑音分散を作る。
4. 観測と信号テンプレートの両方に雑音標準偏差の逆数を掛け、1経路モデルと動的2経路モデルを同じ重みで再適合する。

信号生成の真の雑音分布・遅延・ドップラー・信号強度は入力しない。ブロック間の変動をそのまま雑音とみなす方法と異なり、モデルで説明する反射位相変化を先に取り除く。ただしモデル誤差が残差へ混入する可能性は残る。初期推定が局所ガードを通過しなくても、決められた規則で雑音推定用の予測として使用し、測距結果としては採用しない。

残差重みの推定と再適合に同じ観測を使うため、重みと観測は独立でない。BIC形のスコアを標準分布や事後確率として解釈せず、このデータ再利用を含む処理全体を校正する。局所標準偏差もモデル内の指標であり、厳密な誤差区間ではない。既存の探索範囲・初期値規則・収束・境界・0.1 chip局所標準偏差ガードを維持する。

重みがすべて1の場合に新しい重み付き2経路・1経路フィットが旧実装と完全一致すること、非一様重みで解析勾配と全ブロック残差が一致することをテストした。

## 校正と比較

白色、帯域中央偏重、帯域端偏重の既存3雑音プロファイルそれぞれ408件、合計1224件の新規反射なしデータで校正。各プロファイルの最大スコアを求め、その3閾値の最大値を共通閾値とする。独立同分布という固定した各プロファイルの条件で、真のスコア超過率が1%を超える校正失敗確率を合算すると `3*0.99**408 <= 0.05`。任意の未知PSDや色付き雑音全般に保証するものではない。

今回はまず3分布での誤検出抑制を評価するため最大値方式を使用し、順位による感度改善は別課題とした。旧方式の白色校正済み順位閾値との比較は「雑音重み付け＋校正対象分布の拡張＋閾値規則の変更」が同時に入る。改善を重み付けだけの効果と結論しない。

新規評価は反射なし128件×3分布と、同相反射（電圧比0.8、過剰遅延0.1 chip、ドップラー0 / 0.1 / 0.7 Hz）の16件×3条件×3分布、合計528観測。基準C/N0 37 dB-Hz、PRN1、片側帯域3.6828 MHz、20 ms×10、固定コード遅延、完全除去した直達搬送波・航法ビットを維持する。評価では分布・反射条件間の基礎乱数を共有し、独立標本として合算しない。校正と評価のseedは分離し、校正は各分布間も独立。

主比較は帯域中央偏重の反射なしで、旧方式から新方式へ誤った2経路選択が減るかを対応あり両側正確検定で評価する。2経路を選ばなくても利用不能になる場合があるため、利用不能と測距誤差も併記する。反射ありの結果は小標本の探索的な記述比較とする。

## 結果

プロファイル別の最大校正スコアはwhite -27.177651、center -24.555909、edge -27.566084。共通閾値は最大の **-24.555909** に固定された。新しい反射なし評価（各128件）の結果は次のとおり。

| 雑音分布 | 誤った2経路選択 旧→新 | 利用不能 旧→新 | 10 m未満成功 旧→新 |
|---|---:|---:|---:|
| white | 0→0 | 0→0 | 128→128 |
| center | 63→0 | 29→0 | 96→128 |
| edge | 0→0 | 0→0 | 128→128 |

主比較のcenterでは63件の誤選択を解消し、新たな誤選択は0件、対応あり両側正確p=2.1684e-19。比較対象は以前の試験の67/128件ではなく、今回の同一新規観測で再計算した63/128件。旧方式で2経路を選ばなかった65件には利用不能29件も含まれるため、「誤選択なし」と「測距成功」を区別する。今回は新方式の利用不能も0件だった。

各分布0/128件の誤選択の点ごと両側95%正確区間上限は約2.84%。独立評価だけから1%以下を実証したとは言わない。共通seedの3条件を384独立試行として合算しない。別途、前述の校正手続きが固定3分布に対する同時確率保証を持つ。

同相反射ありの10 m未満成功数（各16件）は次のとおり。

| 雑音分布 | 0 Hz 旧→新 | 0.1 Hz 旧→新 | 0.7 Hz 旧→新 |
|---|---:|---:|---:|
| white | 7→5 | 8→7 | 16→16 |
| center | 6→12 | 6→15 | 15→16 |
| edge | 8→4 | 8→8 | 16→16 |

centerでは感度も改善した一方、whiteとedgeの静止反射では成功数が低下した。各16件の探索的結果なので、その差を母集団で確立した効果とは扱わないが、退行の兆候として明示する。新方式は全反射条件で利用不能0件だったが、推定を返せることと10 m未満の精度は同義でない。旧centerの0 Hzは3件、0.1 Hzは2件が利用不能だった。

今回の変更には重み付け、対象雑音分布の拡張、順位方式から最大値方式への校正规則変更が含まれる。次はこれらを切り分け、誤検出を抑えたまま低ドップラー反射の感度を取り戻す必要がある。今回の評価を見て閾値を下げる処理は行っていない。

17テスト成功。3分布で残差推定が真の相対雑音形状を近似すること、複素振幅スケールに不変なこと、等重みで旧推定器と完全一致すること、重み付き勾配と全残差の一致を確認。監査は校正1224件・評価528件、固定ソースとゲート、全選択と集計、3校正＋5評価ケースの完全再生成を確認した。旧方式も代表2件で旧実装と完全一致。図を comparison.png / comparison.pdf に保存した。

## 再現

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_residual_dynamic_paths_cpu.py tests/test_dynamic_multipath_cpu.py tests/test_calibrated_dynamic_paths_cpu.py tests/test_dynamic_noise_stress.py
# 空の出力ディレクトリでのみ実行可能
python experiments/run_cpu_residual_dynamic.py
python experiments/audit_cpu_residual_dynamic.py
python experiments/plot_cpu_residual_dynamic.py
```

出力は `output/cpu-residual-dynamic/`。全観測・重みのハッシュ、旧新スコア、旧新の選択・誤差・利用不能を保存。実測フロントエンド、森林・雨、時間変化するコード遅延、残留直達搬送波には未対応。
