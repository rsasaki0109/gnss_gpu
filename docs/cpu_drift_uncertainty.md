# 近接する逆位相反射と距離推定の不確かさ

## 目的

前回の [振幅・距離差ストレス試験](cpu_drift_gap_amplitude.md) では、反射電圧比0.8、超過距離0.03 chip（約8.8m）、相対位相π、相対Doppler 0Hzで距離推定が崩れた。単一路を選んだ5例すべてで距離誤差が10m以上だった。本試験は、その条件を新しい乱数で再現し、局所曲率に基づく標準偏差で誤差を説明できるか確認する。

受信機、最適化探索、局所利用可否ガード、反射検出ゲートは変更しない。結果を見て標準偏差のしきい値を調整する試験ではない。

## 事前固定した設計

- 反射なし32例（ID1080000–1080031）、電圧比0.2の弱い逆位相反射32例（1090000–1090031）、電圧比0.8の強い逆位相反射64例（1100000–1100063）。群間も過去試験とも別ID。
- 800ms、PRN1、白色雑音、直接波基準37dBHz、片側帯域3.6828MHz。反射の超過遅延0.03chip、相対Doppler 0Hz。
- 初期共通周波数偏差U[-1,1]Hz、共通周波数ドリフトU[-2,2]Hz/s。他の遅延・位相・雑音生成は過去試験を再利用。
- 既存の独立null校正によるゲート−27.762974167383057をそのまま使用。推定器には真の経路数・反射振幅・距離差を渡さない。
- 推定器が選んだモデルの標準偏差σを距離に変換し、推定値±1.959963984540054σを診断用に計算。これは局所Gaussian近似であり、モデル選択も含めて校正された95%信頼区間ではない。
- 主な集計は全試行に対する距離誤差<10mの成功数、利用可否、利用可能例での区間被覆数、および「区間半幅<10mなのに誤差≥10m」の件数。モデル別集計は選択後の記述統計。
- 成功率・利用可能例の被覆率には点ごとのClopper–Pearson区間を付ける。多重比較全体の同時保証や実環境への保証はしない。

プロトコルとソースハッシュを観測生成前に保存。推定器の変更、再校正、過去データの上書きは行っていない。

実験本体は空の `output/cpu-drift-uncertainty` を要求する。監査はソース、ゲート、成果物ハッシュ、全128例の選択・不確かさ・集計、過去drift試験とのID非重複を確認し、事前指定した各群の端の計6例を完全再計算する。

## 適用範囲

単一衛星の合成信号によるコード距離推定の試験。完全な航法ビット除去と固定した2経路、共通線形ドリフトを仮定する。RFフロントエンド、森林・降雨、動的な散乱、追尾ループ、複数衛星による測位は含まない。結果は実機精度や研究の新規性を証明しない。

## 結果

| 条件 | 距離誤差<10m / 全試行 | 利用不能 | 真値を含む区間 / 利用可能 | 半幅<10mなのに誤差≥10m |
|---|---:|---:|---:|---:|
| 反射なし | 32/32 | 0 | 31/32 | 0 |
| 弱い逆位相反射（電圧比0.2） | 32/32 | 0 | 14/32 | 0 |
| 強い逆位相反射（電圧比0.8） | 25/64 | 26 | 26/38 | 12 |

強い反射での距離成功率は39.1%、点ごとの正確95%区間は27.1–52.1%。前回の4/16と今回の25/64は別標本として扱い、探索に使った前回結果と合算しない。

強い反射64例の選択内訳は、単一路11例、二経路27例、利用不能26例。単一路11例はすべて誤差≥10mで、誤差は−23.10〜−16.85mだった。それでも局所区間の半幅は7.21〜8.09mに収まり、真値を含む例は0/11だった。二経路は25/27例で誤差<10m、26/27例で真値を含み、1例は半幅<10mでも誤差≥10mだった。二経路を選べば必ず安全ともいえない。

弱い反射はすべて単一路を選択し、距離誤差<10mは32/32。しかし局所区間の被覆は14/32（43.8%、正確95%区間26.4–62.3%）にとどまる。粗い距離成功基準を満たしていても、不確かさの数値が正しく校正されているとは限らない。反射なしの被覆31/32も、32例だけで95%校正を証明するものではない。

## 判断と次の実装方針

局所標準偏差は、選択したモデルの近傍での雑音感度を表す。検出できなかった反射による系統的な遅延偏りや、別の経路モデルも観測を説明できる曖昧さを含まない。本試験では、その限界が新しい乱数でも再現した。

したがって「標準偏差が小さいから安全」として既存ガードを強めるだけでは、この失敗は防げない。反射検出ゲートを下げるだけでも、利用不能や二経路推定での失敗は残る。次は、候補モデル・遅延を動かしたプロファイル損失から、観測と両立する距離の広がりを調べる。計算量、境界での非正則性、モデル選択後の校正を別途検証し、局所区間をそのまま保護レベルと呼ばない。
