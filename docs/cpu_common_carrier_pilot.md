# 共通残留搬送波と遅延の同時推定：開発診断

前回の搬送波不整合実験では、直達波を時間一定とする仮定が崩れると、反射なしでも二経路の誤選択や距離推定の棄却が増えた。今回は `common_carrier_paths_cpu.py` に、単一路・二経路の両方で未知の共通搬送波を推定する処理を追加した。

**経路数の自動判定は未実装・未校正。** 以下は前回と同じ192観測を再利用し、生成時の経路数を既知として距離推定を評価する開発診断である。受信機全体の検出性能や未使用データへの一般化を示すものではない。

## 実装

- 単一路：遅延、共通搬送波、複素振幅（実数4パラメータ）。
- 二経路：先行遅延、共通搬送波、超過遅延、相対Doppler、両経路の複素振幅（実数8パラメータ）。
- 直達の時間係数はc(common)、反射はc(common+relative)。cは20 ms矩形窓を積分したsincと位相回転。共通搬送波の解析勾配には両経路の寄与を含める。
- 共通搬送波の探索範囲±2 Hz、相対Doppler±12 Hz。単一路の遅延[-1,2.2] chip、二経路の先行遅延[-1,1]、超過遅延[.01,1.2]。
- 複素振幅を変数消去し、時間・周波数に分離した内積で目的関数と解析勾配を計算。決定的な粗探索から12開始点を選びL-BFGS-Bで最適化する。単一路の観測由来推定値を二経路の候補開始点にも使う。
- 単位重みの単一路・二経路推定後、二経路の推定残差から101調波平滑化PSDを作り、同じ重みで単一路・二経路を1回ずつ再推定する。真の搬送波・遅延・経路数は推定器に渡さない。
- 局所情報行列は未知の複素振幅を射影除去し、共通搬送波を含む。収束、境界からの距離、局所遅延標準偏差0.1 chip以下を検査する。

スコアはn log(SSE1/SSE2)−4 log(n)。形式は旧スコアと同じでもモデルと推定過程が変わったため、**旧閾値は適用しない**。局所ガードを通過しても、検出や実際の誤差を保証するものではない。

## 実験条件

前回 `cpu-residual-carrier-stress` の全192例を選別せず再実行。PRN1、白色雑音37 reference dB-Hz、10×20 ms、片側帯域3.6828 MHz。反射なし、または電圧比0.8・超過遅延0.1 chip・相対Doppler+0.7 Hz・初期相対位相0。共通残留搬送波0/0.1/0.5/1 Hz、各条件24例。

両モデルを全観測で推定した後、診断集計だけで真の経路数に対応する推定を選ぶ。旧処理も同じ経路数の推定と比較する。旧単一路は収束と境界のみ、新単一路は局所標準偏差も検査するため、ガードは完全同一ではない。旧自動選択の成功数は別欄としてreport.jsonに残し、新処理の自動検出改善とは比較しない。

共通乱数により搬送波条件間は対応しており、192例を独立標本として合算しない。既に確認済みの開発データを再利用しているため、検定による優越性を主張しない。

## 結果

距離誤差10 m未満の件数。各欄24例、両処理とも経路数を既知として比較。

| 共通残差 Hz | 反射なし：旧→新 | 反射あり：旧→新 |
|---:|---:|---:|
| 0 | 24→24 | 24→24 |
| 0.1 | 24→24 | 24→24 |
| 0.5 | 24→24 | 16→24 |
| 1 | 24→24 | 5→23 |

反射ありの0.5 Hzでは8例、1 Hzでは18例が新たに成功し、逆方向の変化はなかった。新処理は全条件で利用不能0例。ただし1 Hzの反射ありで1例は局所ガードを通過しながら誤差10 m以上となった（replica 761017、−11.22 m）。局所情報の検査は実誤差の保証にはならない。

反射なしでは**旧単一路推定も全条件24/24成功**している。前回の自動選択の成功数が0.5 Hzで3/24、1 Hzで2/24だったことは、単一路の距離推定自体よりもモデル選択が問題だったことを示す。今回の既知経路数での24/24を「偽二経路検出を解決した」と解釈してはならない。

新処理の共通搬送波の平均絶対誤差は反射なしで0.049〜0.053 Hz、反射ありで0.104〜0.130 Hz。これも当該開発データの記述統計である。

## 検証・再現と次の段階

新規推定器テスト7件、既存の搬送波生成・残差重み付き処理と合わせて14件が成功。解析勾配と有限差分、分離内積と明示的な残差最小二乗、正負の未知搬送波を含む無雑音復元、雑音重みの複素スケール不変性、不正入力の拒否を確認した。

監査は全192観測の旧信号ハッシュとの一致、タスク順序、ソース・旧成果物の不変性、集計の再計算に加え、8条件各1件のフル再実行を行い、すべて一致した。成果物は `output/cpu-common-carrier-pilot/` に保存。

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_common_carrier_paths_cpu.py tests/test_residual_carrier_stress.py tests/test_residual_dynamic_paths_cpu.py
# Requires an empty output/cpu-common-carrier-pilot directory
python -m experiments.run_cpu_common_carrier
python -m experiments.audit_cpu_common_carrier
python -m experiments.plot_cpu_common_carrier
```

次は新しい推定工程全体の独立校正と、自動モデル選択の未使用観測での検証が必要。共通残差の範囲を含む校正分布を事前に定義する必要がある。有限個の残差点での校正は、その間や範囲外に一様な保証を与えない。

この実験は狭帯域・固定コード遅延・白色雑音の合成信号である。追尾ループ、調波間漏洩、ナビゲーションビット、測定器由来の雑音、森林・雨や複数衛星の測位は未検証。
