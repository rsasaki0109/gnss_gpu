# 動的2経路スコアの順位校正

低ドップラー同相反射の検出感度を改善するため、既存の動的推定器・スコア・局所ガードを固定し、校正閾値の選び方を比較した。評価結果を見て閾値を調整することはせず、標本数と確率予算だけで順位を決定する。

## 事前設計

新規の反射なしデータ1000件を生成し、次の2閾値を同じスコア集合から計算する。

- 最大値方式：1000件中の最大スコア。
- 順位方式：1000件中、上から5番目のスコア。

独立同分布の帰無スコアに対し、k番目の閾値の真の超過率がαを上回る校正失敗確率は `BinomialCDF(k-1; n, α)` 以下。n=1000、α=0.01、失敗確率予算δ=0.05だけから許容する最大kを選ぶとk=5になる。実際の上界は約0.02869で、k=6では0.05を超える。厳密な閾値超過だけを採用し、同点は保守的に扱う。最大値方式は同じ標本の順位方式より厳しいため、同じ校正成功イベントで覆われる。

これは固定した帰無分布に対する校正保証であり、観測した誤選択率の信頼区間や、任意環境での保証ではない。前回の299件最大値ゲートもそのまま比較するが、既に観察した開発上の参考であり、今回の確認的比較には含めない。

モデルはPRN1、白色Gaussian雑音、基準C/N0 37 dB-Hz、片側帯域3.6828 MHz、20 ms×10、直達搬送波・航法ビットを完全除去、固定の遅延探索補助。同相反射の電圧比0.8、過剰遅延0.1 chip、ドップラー0 / 0.1 / 0.7 Hzを評価。時間変化するコード遅延や色付き雑音は含まない。

校正1000件、評価の反射なし299件、反射あり各128件は互いに異なるseed。反射ありの3条件は同じ128雑音実現を共有するので、条件を独立試行として合算しない。校正結果を保存・固定してから評価を開始。0 / 0.1 Hzの測距成功（絶対誤差10 m未満、利用不能は失敗）について、順位方式対同じ1000件の最大値方式を対応あり両側正確検定で比較し、2検定にBonferroni補正。0.7 Hzは記述的な対照とする。校正実現は1組であり、校正変動の安定性は未検証。

## 固定された閾値

今回の最大値は -25.241523891、5番目の順位閾値は -27.522660889。前回299件の最大値 -17.254451768 との差も大きい。前回との性能差には校正標本の実現の違いが含まれるため、その差を順位化の効果として扱わない。順位方式自体の効果は同じ新規1000件の最大値との差で評価する。

## 評価結果

同じ新規評価信号に対する10 m未満の成功数は次のとおり。

| 条件 | 同じ1000件の最大値方式 | 順位方式 | 前回299件の閾値（参考） |
|---|---:|---:|---:|
| 反射なし | 299 / 299 | 299 / 299 | 299 / 299 |
| 同相反射 0 Hz | 56 / 128 | 73 / 128 | 22 / 128 |
| 同相反射 0.1 Hz | 72 / 128 | 83 / 128 | 24 / 128 |
| 同相反射 0.7 Hz | 124 / 128 | 124 / 128 | 124 / 128 |

順位方式対同じ1000件の最大値方式では、0 Hzは17改善・0悪化、補正p=3.0518e-5。0.1 Hzは11改善・0悪化、補正p=0.001953。事前に指定した両比較で改善を確認した。ただし順位方式でも静止反射55/128件、0.1 Hz反射45/128件が10 m成功条件を満たさず、問題は解消していない。全方式・全評価で利用不能は0件だったが、これは測距誤差の小ささを保証しない。

反射なしの誤った2経路選択は、同じ1000件の最大値と順位方式がともに2/299件（0.669%）、前回299件の閾値は0/299件。2/299の点ごと両側95%正確区間は約0.081–2.395%。誤検出の増加は今回の最大値対順位の比較では観測しなかったが、真の誤検出率が等しい、または評価から1%以下と実証できた、という意味ではない。校正の確率保証は前述の固定帰無モデルに限定される。

前回の厳しい閾値との差（例えば0 Hzの22→73件）には、校正標本の違いが大きく含まれる。順位化だけの比較は56→73件である。1000件へ増やせば必ず閾値が低下するという結果でもない。今回1組の校正だけでは順位方式の安定性を証明できない。

新しい閾値は測距成功を改善したものの、実測環境や色付き雑音への保証は追加していない。今後は独立した校正実現での変動と、雑音モデルがずれた条件での誤検出を確認する必要がある。

14テスト成功。順位をデータ値ではなく確率予算から決めること、同一標本の最大値との比較、対応のある分母と2比較の補正を確認した。監査は校正1000件・評価683件の全件対応、校正/評価seed分離、固定ソースと旧ゲート、順位と閾値、全判定・集計、5件の完全再生成を確認した。図を comparison.png / comparison.pdf に保存した。
