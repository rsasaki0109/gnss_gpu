# 時間変化を残した2経路推定の予備実装

20 msブロックを平均に潰さず、直達遅延・反射の過剰遅延・未知の反射ドップラーを同時推定するCPU実装を追加した。以前は利用不能だった29件のうち28件で、局所安定性のガードを通過し、直達波測距誤差が10 m未満になった。ただし新実装は2経路を必ず仮定する診断用推定器で、反射の有無を判定する校正済み受信機ではない。

## 実装

`python/gnss_gpu/dynamic_multipath_cpu.py` の `fit_dynamic_paths(blocks)` は10×7365複素観測値のみを受け取る。真の遅延・ドップラー・位相・振幅・C/N0は入力しない。直達波の搬送波と航法ビットは完全に除去済み、白色雑音、PRN1、片側帯域3.6828 MHz、20 ms×10ブロックを仮定する。

モデルは直達波の時間一定成分と、未知ドップラーで回転する反射成分の和。反射位相は20 ms区間内で解析的に平均し、コード遅延は一定とする狭帯域近似。複素振幅2個は最小二乗で消去し、直達遅延[-1,1] chip、過剰遅延[0.01,1.2] chip、反射ドップラー[-12,12] Hzを最適化する。粗い固定グリッドから12初期値を選ぶ。シミュレーション真値による初期化は使わない。

時間と周波数の積の形を利用し、全ブロックの二乗残差を2×2 Gram行列と観測との相関から計算する。全サンプルを保持した残差と一致することをテストした。無雑音に近い場合は大きいエネルギー同士の引き算を避け、直接残差を計算する。浮動小数点レベルの等価解には既存の収束済み候補選択ルールを使用。未知ドップラーを含む局所情報行列で直達遅延の標準偏差を求め、収束・探索境界・0.1 chip以下の局所標準偏差を確認する。

ここで返す `locally_usable` は反射検出や測距誤差の保証を意味しない。2経路を常に当てはめるため、直達波だけの信号に対する誤検出を抑える仕組みは未実装。従来の校正閾値は新モデルに流用していない。また従来方式の推定雑音重みから白色雑音の等重みへ変えており、この比較だけで改善を時間情報のみの効果と断定しない。

## 評価

元の狭帯域合成信号と同じ条件：白色雑音37 dB-Hz、反射電圧比0.8、過剰遅延0.1 chip、相対ドップラー0.7 / 2.3 / 6.7 Hz、初期相対位相0 / π/2 / π。

既知の利用不能29件を全件再生成し、さらに独立した新規seedで9条件×8実現の72件を評価した。条件間では同じ8雑音実現を共有するため、72件を独立標本として扱わない。実行前にタスク・ソース・旧ゲートのハッシュを固定した。小規模な探索的評価で、確認的な有意差検定は行っていない。

| パネル | 旧方式の10 m未満成功 | 新方式の局所ガード通過かつ10 m未満成功 |
|---|---:|---:|
| 既知の利用不能ケース | 0 / 29 | 28 / 29 |
| 新規9条件×8件 | 71 / 72 | 72 / 72 |

新方式は全101件で収束と局所ガードを通過。既知の失敗のうち0.7 Hz・初期位相πの1件は依然10 m誤差基準を超えた。局所ガード通過は測距成功の保証ではない。新規パネルの差は2.3 Hz・π/2の1件のみで、他の条件は両方式とも8/8成功。各条件8件という小標本のため、一般的な優位性は示せていない。

既知失敗29件は開発で観察済みの事後評価であり、回復28件を独立した検証成果として扱わない。実測の森林・雨やPVT、残留直達ドップラー、時間変化するコード遅延、色付き雑音は未評価。次は直達波だけの場合とドップラーゼロ付近の反射で、誤った2経路推定や識別の不安定さを調べ、モデル選択用のスコアと独立校正を追加する。

## 検証と再現

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_dynamic_multipath_cpu.py tests/test_noise_aware_multipath_cpu.py tests/test_matched_dynamic_reflection.py
# 出力ディレクトリが空の場合のみ
python experiments/run_cpu_dynamic_path_fit.py
python experiments/audit_cpu_dynamic_path_fit.py
python experiments/plot_cpu_dynamic_path_fit.py
```

新規9件と既存10件、計19テスト成功。正負の未知ドップラーの無雑音復元、解析勾配と有限差分、時間係数の微分、雑音ありの全ブロック残差との一致、不正入力を検証。監査は101件の完全性・固定ハッシュ・旧失敗29件の観測と旧結果の完全一致・集計再計算・3件の全再生成を確認した。出力は `output/cpu-dynamic-path-fit/`。既存推定器と過去の結果は変更していない。
