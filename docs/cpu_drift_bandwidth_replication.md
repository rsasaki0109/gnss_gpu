# 帯域拡大の独立追試

## 目的と事前固定した比較

[最初の帯域試験](cpu_drift_bandwidth.md)では、片側帯域3.68MHzから7.37MHzへの拡大により、近接反射16例の距離成功が2/16から11/16へ増えた。本試験は別の乱数でその効果を検証する。前回の16例は今回の解析に合算しない。

- 反射あり64組（ID1260000–1260063）、反射なし32組（ID1250000–1250031）。各組を3.6・7.2チップレートの片側帯域で処理し、計192観測とする。
- 800ms、PRN1、直接波のフィルタ前C/N0=37dBHz、白色雑音のスペクトル密度を一定とする。
- 反射ありは電圧比0.8、超過遅延0.03chip、位相π、相対Doppler 0Hz。共通初期周波数・線形ドリフトの分布は前回と同じ。
- 広帯域の信号・雑音の部分集合を狭帯域に用いる。重なる周波数成分のIQと信号は完全一致する。信号を帯域内電力で再正規化せず、総雑音電力も固定しない。
- 既存の帯域可変受信機、探索、重み推定、局所ガードを固定する。帯域別の経路選択ゲートは使用しない。

主比較は「反射ありの64組で、利用可能かつ距離誤差10m未満となる割合が両帯域で同じか」。対応する成功/失敗が変わった組だけを使う両側正確McNemar検定（不一致組の二項検定）を1つだけ行う。有意水準は0.05。利用不能を除外せず失敗として数え、途中結果による打ち切りや条件変更はしない。

反射なしの32組は記述的な対照であり、追加の仮説検定はしない。各セルの成功率に付けるClopper–Pearson区間は点ごとの95%区間で、全セルを同時に覆う保証ではない。

## 経路数を既知とする限界

推定器のパラメータ探索には真の距離や反射振幅を渡さない。ただし評価時には、反射ありで二経路フィット、反射なしで単一路フィットを使う。このため、反射なしの成功率はモデル選択を含めた測位成功率でも、反射の誤検出率でもない。

広帯域の自動経路選択や警報へ組み込むには、広帯域の独立nullデータで改めて校正する必要がある。今回の結果だけで既存の校正ゲートを流用しない。

## 再現と監査

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_drift_bandwidth_replication.py tests/test_bandwidth_drift_paths.py
python -m experiments.replicate_cpu_drift_bandwidth
python -m experiments.audit_cpu_drift_bandwidth_replication
python -m experiments.plot_cpu_drift_bandwidth_replication
```

実験本体は空の `output/cpu-drift-bandwidth-replication` を要求する。プロトコル、全ソースハッシュ、192観測のフィット・成功判定・生成IQハッシュ、集計を保存する。

テストでは反射なしの信号生成、雑音の共通化、帯域の完全な入れ子関係、前回と同じ反射信号生成、対応検定の既知の値と不正な対応付けを確認する。前回の帯域一般化テストも含めて5件が通過した。

監査では全192観測、96組のIQ・信号の完全一致、全成功判定、過去試験とのID非重複、ソース・成果物ハッシュを確認する。主要検定のp値は独立した二項係数の和でも再計算し、4条件それぞれから1例を完全再実行する。

## 適用範囲

単一衛星・固定反射・理想的コヒーレント積分・白色雑音・共通線形ドリフトの合成信号に限定する。森林、降雨、RFフィルタ、量子化、追尾ループ、複数衛星の測位性能や実機の改善を証明するものではない。今回の試験で計算速度は再計測せず、前回のCPU時間は小規模な参考計測として残す。

## 追試結果

| 条件 | 片側帯域 | 成功 | 利用不能 | 利用可能だが誤差≥10m |
|---|---:|---:|---:|---:|
| 反射なし | 3.68MHz | 32/32 | 0 | 0 |
| 反射なし | 7.37MHz | 32/32 | 0 | 0 |
| 近接逆位相反射 | 3.68MHz | 23/64 | 31 | 10 |
| 近接逆位相反射 | 7.37MHz | 34/64 | 29 | 1 |

反射ありの成功率は35.9%から53.1%へ、17.19パーセントポイント増えた。対応内訳は回復19組・損失8組・両方成功15組・両方失敗22組だった。

事前指定した両側正確検定は **p=0.052238985896110535** で、有意水準0.05を下回らなかった。したがって、改善傾向は観測したが、今回の追試で設定した基準に沿って効果を統計的に確認できたとは結論しない。片側検定への事後変更、前回パイロットとの合算、成功基準の変更は行わない。同時に、有意でなかったことは効果がない証明でもない。

成功率の点ごとの正確95%区間は、3.68MHzで24.3〜48.9%、7.37MHzで40.2〜65.7%。反射なしの32/32は両帯域とも89.1〜100%であり、実運用で失敗がないことの保証ではない。

## 残る利用不能の事後診断

反射ありでの利用不能は、3.68MHzの31例、7.37MHzの29例とも、超過遅延パラメータの探索境界への到達だった。

局所ガードを無視した推定値だけを見ると、誤差10m未満は3.68MHzで54/64、7.37MHzで63/64。広帯域の残る1例はID1260017で−10.117mだった。ただし、この集計は事後的な原因診断であり、主評価の成功数23/64・34/64を置き換えない。真値に近かったという事後結果だけで境界解を利用可能にしてはいけない。

次は、広帯域で境界に達する解について、遅延の識別可能性と利用可否ガードの挙動を調べる。既存のガードを一律に緩和せず、境界を変えたときに損失・推定距離・不確かさがどう変わるかを診断する。さらに自動経路選択まで評価する場合は、別データでの帯域別校正が必要となる。

## 検証完了

関連テスト5件が通過。監査では全192観測・96組の共通帯域一致・全成功判定・過去ID非重複・ソースと成果物を確認し、主要p値を二項係数の和から独立再計算した。4条件の完全再実行も一致した。
