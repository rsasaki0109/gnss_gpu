# 広帯域受信機の反射位相・相対Doppler感度

## 目的

[前回のC/N₀試験](cpu_wideband_cn0.md)では、逆位相・相対Dopplerゼロの近接反射で、雑音を減らすと成功が20/32から27/32へ増えた。今回は固定していた反射位相と相対Dopplerを変え、同じ傾向が他の条件にも続くかを探索的に調べる。

## 固定した条件

- 片側帯域7.3656MHz、800ms、PRN1、反射電圧比0.8、超過遅延0.03chip。
- 初期相対位相0・π/2・π、相対Doppler 0・0.7Hz、直接波基準C/N₀ 37・49dB-Hzの計12条件。
- 未使用16乱数ID（1310000–1310015）を全条件で共有し、計192観測。直接波遅延、共通位相、初期共通周波数、共通ドリフト、標準化した雑音を共有する。
- 受信機・残差重み推定・探索範囲・ガードは固定。前回の位相π・相対Doppler 0Hzの生成結果は完全に一致させる。
- 経路数2を既知として評価する。生成時の位相・Doppler・遅延・振幅をパラメータ最適化に渡さず、経路選択や警報ゲートも使わない。

信号生成では、直接波の共通周波数fとドリフトaに対して、反射波は初期位相θと周波数f+Δfを持ち、両波に同じaを使う。20msごとの複素信号平均を積分する。Δf=0.7Hzでは800msで相対位相が約201.6度回転する。

直接波C/N₀は固定するが、合成信号の電力は位相・Dopplerによって変わる。合成信号の総SNRを揃えた比較ではなく、打ち消し合いも含む反射条件の感度試験である。

## 評価と解釈

利用可能と判定され、距離誤差10m未満なら成功とする。全16例を分母とし、利用不能を除外しない。各条件の成功率と点ごとのClopper–Pearson 95%区間、利用不能、利用可能だが10m以上の誤差、収束・境界への到達を集計する。

各位相・Doppler条件で、37→49dB-Hzの対応する回復・悪化も記録する。今回は探索的な12条件の比較であり、有意差検定は行わない。共通16乱数を192個の独立標本としてプールせず、区間の同時保証もしない。16/16成功でも母集団の成功率100%を意味せず、その正確95%区間の下限は約79.4%となる。

## 適用範囲

相対キャリア位相は時間変化させるが、コード遅延は固定した近似モデルである。移動反射物の幾何、コード距離変化、遮蔽、振幅変化を整合的に生成する完全な移動環境ではない。森林・雨・実機RF・追尾ループ・複数衛星測位の性能も示さない。実用のモデル選択へ組み込む場合は、別データでの校正が必要になる。

| 0Hz | 90度 | 16 / 0 / 0 | 16 / 0 / 0 | 0 / 0 |
| 0Hz | 180度 | 10 / 6 / 0 | 14 / 2 / 0 | 4 / 0 |
| 0.7Hz | 0度 | 16 / 0 / 0 | 16 / 0 / 0 | 0 / 0 |
| 0.7Hz | 90度 | 16 / 0 / 0 | 16 / 0 / 0 | 0 / 0 |
| 0.7Hz | 180度 | 16 / 0 / 0 | 16 / 0 / 0 | 0 / 0 |

全条件で最適化は収束した。利用不能は全て探索境界によるものだった。相対Doppler 0Hz・位相0度・37dB-Hzでは、利用可能と判定されながら距離誤差10m以上となる例が2件あり、局所ガードが大きな誤差を完全に防ぐわけではない。

今回の標本では、相対Doppler 0.7Hzの各条件は全16例成功した。これは800msにわたる時間変化が経路分離に役立つ可能性と整合する。一方、相対Dopplerに伴って干渉と合成信号電力も変わるため、この試験だけで「時間方向の識別情報だけが原因」と切り分けてはいない。0.7Hz以外の全Dopplerや全位相を保証する結果でもない。

相対Dopplerゼロでは位相の影響が残り、逆位相の条件は49dB-Hzでも2例が利用不能だった。高C/N₀なら反射条件によらず解決するとはいえない。今回は探索的比較として事前に固定しており、結果に応じた有意差検定の追加や条件の選別はしていない。

## 次の実装に向けて

次は、相対Dopplerとコード遅延の時間変化を整合させた信号生成を検証する。今回の「キャリアだけが相対的に変化し、コード距離は固定」という近似から進め、移動する経路で生成した信号に既存受信機を適用した場合の誤差を調べる。まずは単純な一定距離変化率から始め、複雑な森林や降雨を再現したと主張しない。

受信機や警報ゲートは変更しない。経路数既知での成功結果を、そのまま未知経路数の検出性能として扱わない。
