# 反射の振幅・超過遅延を変えた経路選択と距離推定

ドリフト推定器の反射位相・周波数差に続き、これまで固定だった反射の電圧比と超過遅延を変えた。受信処理と校正閾値は固定し、弱い反射や近接した反射での検出と距離推定を分けて調べる。

## 実験条件

- 凍結済み `cached_drift_carrier_paths_cpu.py` と閾値 **−27.762974167383057** を使用。
- PRN1、800 ms、白色雑音37 reference dB-Hz、片側帯域3.6828 MHz。
- 共通周波数変化率は一様分布[-2,2] Hz/秒、初期周波数は一様分布[-1,1] Hz。
- 相対Doppler0 Hz。電圧比0.2/0.8 × 超過遅延0.03/0.1/0.3 chip × 初期位相0/180度の12条件、各16例。
- 超過遅延は距離差に換算して約8.8/29.3/87.9 m。受信機からの絶対距離や距離誤差そのものではない。
- 全反射条件で同じ16乱数ID1060000〜を共有し、直達信号と雑音を揃える。別の反射なし32例はID1050000〜。計224観測。

反射の電圧比と超過遅延の真値は推定器に渡さない。電圧比0.8・超過遅延0.1 chipの場合は既存生成器と完全一致する。ほかの条件は信号だけを変更し、加算雑音を共通化する。

## 評価の読み方

経路選択と距離成功は異なる評価軸。反射を単一路として扱っても距離誤差が10 m未満なら距離成功と数える。逆に二経路を選んでも距離が正しいとは限らない。利用不能は距離成功の分母に含める。既知経路数での距離結果も参考診断として保存する。

各条件16例は共有乱数による対応標本であり、独立な192反射観測として合算しない。記述的な探索で、有意差検定や結果に合わせた閾値・ガードの変更を行わない。正確95%区間は点別で同時区間ではない。

元の帰無分布と同じ反射なし条件を32例追加するが、0件でも1%誤検出率を認証できる標本数ではない。今回の小規模な反射条件の結果を任意の反射に一般化しない。

### 強い近接反射が逆位相になる場合

電圧比0.8・超過遅延0.03 chip・180度では、距離成功が4/16（25%、点別正確95%区間7.27〜52.38%）に低下した。内訳は次の通り。

- 6例：スコアは閾値を超えたが、二経路推定が探索境界に達して利用不能。
- 5例：単一路を選択し、すべて距離誤差10 m以上。
- 5例：二経路を選択し、4例は距離成功、1例は距離誤差10 m以上。

既知二経路で計算しても成功は6/16、利用不能8/16。自動選択によって失われた成功は2例であり、閾値を下げて二経路を増やすだけでは全失敗を解消できない。近接経路の識別、探索境界、モデル選択の影響が同時に含まれる。

### 検出できない反射と距離誤差の区別

電圧比0.2・超過遅延0.03 chipでは、両位相とも反射を二経路として選んだ例は0/16だが、距離成功は16/16だった。電圧比0.8の同位相・同じ遅延でも同様だった。この3条件では既知二経路の距離成功は各14/16にとどまり、単一路を許す自動選択が2例ずつ成功を保っている。

したがって「反射を必ず検出すること」と「使える距離を返すこと」は同じ目標ではない。ただし、強い近接逆位相では単一路の距離に大きな偏りが残りうる。現在の局所ガードは、別モデルが成立する可能性まで含めた距離誤差の保証にはなっていない。

次の課題は、この難条件を独立な標本で再確認するとともに、二経路だけでなく単一路を選んだ場合の距離の不確かさも評価することである。今回の失敗例に合わせて既存閾値やガードは変更していない。

## 検証・再現

基準信号の完全一致、全12反射条件の共通雑音、弱く近接した逆位相反射の信号と独立した時間積分の一致を確認。キャッシュ同等性と選択処理を合わせて7テストが成功。監査では全224判定と集計、ソース・閾値のハッシュ、既存校正・評価とのID非重複を確認した。全13条件から各1例を高速化版で再実行し、そのうち3例を元実装でも再実行して推定値・スコア・雑音重みの完全一致を確認した。

```bash
source /workspace/.gnss-env/activate.sh

```
