# 共通周波数変化率を推定する単一路・二経路モデル

800 msの反射なしドリフト信号を反射と誤認する問題に対し、共通搬送波の線形変化率を未知量として推定するモデルを追加した。単一路と二経路の両方を同じように拡張し、単一路側の表現不足を二経路で補う比較にならないようにした。

**今回のスコアは未校正。自動モデル選択は行わず、旧閾値も適用しない。** 以前のデータを使ったモデル適合の開発診断であり、誤検出率の改善を検証する段階ではない。

## 実装

`drift_carrier_paths_cpu.py` に次を実装した。

- 単一路：遅延、初期共通周波数、共通周波数変化率、複素振幅（実数5パラメータ）。
- 二経路：先行遅延、初期共通周波数、共通周波数変化率、超過遅延、相対Doppler、各経路の複素振幅（実数9パラメータ）。
- 直達位相2π(f0 t+a t²/2)、反射は初期周波数をf0+relativeに置き換える。両経路は同じ変化率aを共有する。
- 各20 msブロックを24点Gauss–Legendre積分。初期周波数の微分は2πit、変化率の微分はπit²を被積分関数へ掛けて求める。共通量の勾配には両経路の寄与を含める。
- 初期共通周波数±2 Hz、変化率±3 Hz/秒、相対Doppler±12 Hz。遅延範囲と局所ガードは既存モデルを踏襲。
- 複素振幅を消去した最小二乗、12開始点、最大300反復。単一路の粗探索では変化率−2/0/2を候補とする。二経路では観測由来の単一路変化率と0を候補に加え、単一路の初期周波数・遅延も開始点候補に用いる。単一路初期値を渡さない単独の二経路呼出しでは−2/0/2を使用。
- 単位重みの予備単一路・二経路推定→二経路残差PSD推定→同じ重みで単一路・二経路の再推定、という工程。真の遅延・周波数・変化率・経路数は推定器に渡さない。

スコアはn log(SSE1/SSE2)−4 log(n)。パラメータ差が4なので式は以前と同じだが、推定工程と帰無分布が異なるため旧校正は使えない。局所情報行列には変化率も含め、自由度補正は5/9パラメータに対応させる。

## 開発診断の選び方

`cpu-drift-null-selection` の反射なしデータと `cpu-carrier-drift-stress` の反射ありデータから、800 ms・各データセットの先頭8個のreplica ID・全3変化率0/0.5/2 Hz/秒を選択した。成功や失敗を条件にしない決定的な選択で、計48観測。実行前に対象ID・元成果物ハッシュ・ソースハッシュを保存した。

両推定をすべての観測で実行した後、距離診断の集計に限り生成時の経路数を使う。誤差10 m未満を成功とし、利用不能は失敗に含める。元のスコアと新スコアも保存するが、閾値による判定はしない。

以前に検査したデータであり、未使用データへの一般化を示すものではない。各条件8例は変化率間で共有され、独立な48例として合算しない。新スコアが低下しただけで偽二経路率が下がったと主張しない。

## 結果

各条件8例。スコアは大きいほど二経路が相対的に有利になる指標だが、今回の値に検出閾値は適用していない。

| 反射なし | 0 | −46.36〜−33.56 | −46.08〜−36.25 | 8→8 |
| 反射なし | 0.5 | −33.09〜+1.28 | −46.27〜−36.48 | 8→8 |

| 反射あり | 0 | +526.08〜+628.37 | +526.11〜+616.56 | 7→7 |

| 反射あり | 2 | +429.00〜+588.59 | +455.35〜+628.30 | 8→8 |

反射なしでドリフトを増やすと旧スコアは大幅に上昇したが、新モデルではゼロドリフトに近い範囲となった。今回の反射ありデータでは高いスコアを保っている。単一路でドリフトを表現することで、存在しない反射を導入する相対的な利得が小さくなったという説明と整合する。

既知経路数での距離成功分類は全48観測で旧処理と同じだった。反射なしの単一路推定はもともと距離が合っていたため、距離成功数の増加は期待する評価軸ではない。今回の主要な観察はスコアの変化であり、誤検出率の推定ではない。

新しい変化率推定の平均絶対誤差は、反射なしで0.041/0.050/0.090 Hz/秒、反射ありで0.140/0.129/0.101 Hz/秒（真値0/0.5/2の順）。これは当該少数の開発データの記述統計である。反射あり・変化率0の1例（replica 920007、探索境界）は利用不能のままで、全48例を回復したわけではない。

次は新しい推定工程全体を独立な反射なしデータで校正し、未使用の反射なし・反射あり信号で自動選択を検証する。校正に使うドリフト分布を事前に決め、分布平均の保証と各変化率での保証を区別する必要がある。今回のスコア分離だけを根拠に「誤検出を解決した」とは結論づけない。

## 検証・再現

解析勾配と有限差分、明示的残差との一致、変化率0で既存モデルと目的関数が一致すること、正負の未知変化率を持つ無雑音単一路の復元、無雑音二経路の全パラメータ復元、時間係数の微分、不正入力を確認した。6テストが成功。監査では全48観測の元信号ハッシュとの一致、対象選択、ソースと元成果物の不変性、集計を確認した。全6条件から各1例のフル再実行も完全一致した。

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_drift_carrier_paths_cpu.py
# Requires an empty output/cpu-drift-model-pilot directory
python -m experiments.run_cpu_drift_model_pilot

python -m experiments.plot_cpu_drift_model_pilot
```
