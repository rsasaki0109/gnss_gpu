# 低相対Doppler・逆位相での共通搬送波推定と経路選択

受信処理と白色雑音の校正閾値を固定し、反射を見分けにくい条件を探索した。共通残留搬送波を推定できても、直達波と反射波の相対的な時間変化や位相によって、経路の識別と距離推定が難しくなる可能性がある。

## 設計

- `common_carrier_paths_cpu.py` と `calibrated_common_carrier_cpu.py` を変更せず利用。閾値は `cpu-common-carrier-selection/frozen_gate.json` の−24.99826377099785。
- PRN1、白色雑音37 reference dB-Hz、200 ms（10×20 ms）、片側帯域3.6828 MHz。共通搬送波残差は一様分布[-1,1] Hz。
- 反射の電圧比0.8、超過遅延0.1 chip。相対Doppler 0/0.1/0.7 Hz × 初期相対位相0/90/180度の9条件、各16例。
- 同じ16個の乱数ID880000〜を全反射条件で共有し、直達遅延・共通位相・共通搬送波・加算雑音を揃える。独立の反射なし32例はID870000〜。以前の校正・評価とIDは重複しない。
- 全タスク、ソースハッシュ、閾値とそのハッシュ、推論の範囲を実行前に保存。結果を見た閾値や探索設定の調整はしない。

直達の時間係数はc(common)、反射はexp(i phase)c(common+relative)。cは矩形20 ms区間を積分したsincと位相回転。初期位相180度でも相対Dopplerが非ゼロなら位相差は時間変化するため、「200 ms全体で完全に逆位相」とは限らない。超過遅延があるため相対Doppler0・180度でも帯域全体の信号が一様に打ち消されるわけではない。

距離成功は絶対誤差10 m未満で利用不能を失敗に含める。既知経路数での推定結果は参考診断として別に集計する。9条件を共有乱数の独立な144標本とみなさない。探索的・記述的な比較で有意差検定は行わず、正確95%区間は点別で同時区間ではない。

### 異なる二つの失敗

**低相対Doppler・同位相**では、0 Hzと0.1 Hzの両方で二経路選択が7/16にとどまった。既知経路数の推定では成功していた6例が、自動選択では失敗した。0.1 Hzでは逆に、既知二経路推定が失敗し単一路選択が成功した例も1例あり、単純な成功数差だけでは取りこぼし数を表せない。二経路を常に選ぶことで全部解決するわけではない。

**初期逆位相**では、利用不能の5・6・2例すべてが超過遅延の探索境界に達した二経路推定だった。経路数を既知にしても同じガードで棄却されるため、これらは閾値を下げるだけでは解消しない。現時点では、最適化の局所解と信号情報の不足のどちらが主因かを断定しない。境界を外せば妥当な距離推定が得られるとも言えない。

16/16成功の90度条件も、成功率の点別正確95%下限は約79.41%。少数の対応標本による探索であり、全位相への頑健性や条件間の有意差を主張しない。

次の診断対象は、逆位相で探索境界に達した全13観測。重みを固定して開始点を広げる比較と、明示的な最小二乗残差との照合により、数値的な探索失敗なのか、境界解が残差を小さくするのかを切り分ける。既存の受信処理・判定閾値を変更する前に、この原因を確認する。

## 検証と再現

生成器は既存の相対Doppler0.7 Hz・位相0の信号をビット単位で再現する。全9条件で雑音が共通であることと、独立した時間数値積分による信号の一致を確認した。既存の共通搬送波推定・選択テストと合わせて11件が成功。監査では全176件の選択と集計を再計算し、固定ソース・閾値のハッシュと以前の校正・評価とのID非重複を確認した。反射なし1条件と反射あり9条件の計10例をフル再実行し、完全一致した。

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_common_carrier_phase_stress.py tests/test_calibrated_common_carrier_cpu.py tests/test_common_carrier_paths_cpu.py
# Requires an empty output/cpu-common-carrier-phase-stress directory
python -m experiments.stress_cpu_common_carrier_phase
python -m experiments.audit_cpu_common_carrier_phase
python -m experiments.plot_cpu_common_carrier_phase
```

成果物は `output/cpu-common-carrier-phase-stress/` のprotocol.json、evaluation.jsonl、report.json、completion.json、audit.json、comparison.png/pdf。

反射なし32例は小規模な動作確認であり、1%誤判定率を認証する標本数ではない。狭帯域・固定コード遅延の合成モデルで、追尾ループ、調波間漏洩、ナビゲーションビット、実測雑音、森林・雨、複数衛星PVTを含まない。
