# コード遅延とキャリアDopplerを整合させた移動反射経路

## 実装

以前の反射モデルは、相対キャリア周波数を変えながらコード遅延を固定していた。今回、反射の超過経路長を `L(t)=L0+v*t` とし、同じvからコード遅延とキャリア位相の両方を変化させる生成器を追加した。

GPS L1周波数 `fL1=1575.42MHz` に対し、相対キャリアDopplerは `fd=-fL1*v/c`。正のfdは超過経路が短くなる向きとなる。コードの周波数成分fにも `-f*v*t/c` の位相変化が加わるため、20msブロックで積分する実効周波数は `common-(fL1+f)*v/c` となる。初期遅延と初期相対位相は別途掛ける。

`python/gnss_gpu/moving_echo_cpu.py` はこの式を24点Gauss–Legendre積分で計算する。周波数成分を512個ずつ処理し、積分用の一時配列の大きさを抑える。共通の初期周波数偏差と線形ドリフトは発振器に由来する残差として扱い、直接波の幾何学的移動を意味しない。

既存の周波数成分ごとの観測モデルの中で、コード位相とキャリア位相を整合させた実装である。Dopplerによる周波数ビン間の漏れを含むRF・時間領域波形全体のシミュレーションではない。

## 比較設計

- 未使用16乱数ID（1330000–1330015）を共有し、コード遅延固定/時間変化の2方式と相対Doppler 0・0.7・7・−7Hzで計128観測。
- 片側帯域7.3656MHz、800ms、直接波基準49dB-Hz、PRN1、反射電圧比0.8、初期超過遅延0.03chip、初期相対位相π。
- 反射の超過経路変化率は、0.7Hzで約−0.133m/s、7Hzで約−1.332m/s、−7Hzで約+1.332m/s。±7Hzでは800msで超過経路長が約∓1.066m変わる。
- 初期超過経路長は約8.79mで、全条件で超過長が正のままになることを確認する。直接波の遅延・反射振幅は固定する。
- 固定コードと移動コードで同じ直接波・雑音を使う。速度0は以前の生成器とビット単位で一致する。
- **受信機はコード遅延固定のまま変更しない。** 生成モデルとのずれが距離推定へ与える影響を調べる試験であり、移動経路に対応した新しい受信機の評価ではない。

経路数2を既知として、利用可能かつ直接波距離誤差10m未満を成功とする。反射の中間時刻の超過遅延も診断用に保存するが、直接波の評価真値は固定した直接波遅延であり、反射の中間位置へ置き換えない。

各条件16例の探索的な比較で、点ごとの正確95%区間と対応する回復・悪化を記録する。有意差検定や、共通16乱数を128個の独立標本として扱う集計は行わない。旧ゲートは流用しない。

## 再現と検証

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_moving_echo_cpu.py tests/test_bandwidth_drift_paths.py
python -m experiments.run_cpu_moving_echo_pilot
python -m experiments.audit_cpu_moving_echo_pilot
python -m experiments.plot_cpu_moving_echo_pilot
```

実験本体は空の `output/cpu-moving-echo-pilot` を要求する。全条件とソースハッシュを観測生成前に保存し、生成IQ・重みハッシュ、全フィットと判定を記録する。

関連テスト6件が通過。ドリフトなしの積分を閉形式のsincと比較し、Dopplerの符号を確認した。独立した50,000点の中点積分で時間変化する遅延を直接評価し、速い積分結果と照合した。ゼロ速度の完全一致、雑音共有、既存の帯域受信機のテストも含む。

監査では全128観測、64組の雑音一致、16組のゼロ速度での生成・推定パイプライン完全一致、全距離誤差・経路変化量・成功判定を確認する。各8条件から1例ずつ完全再実行する。

## 制限

一定の超過経路長変化率を扱う最小モデルであり、反射面の位置・角度から経路を計算する幾何モデルではない。加速度、振幅変化、遮蔽、経路の出現消失、森林・雨、RF帯域・量子化、追尾ループ、複数衛星測位は含まない。相対Dopplerとコード位相の整合性が増しても、実環境全体の再現性を検証したとはいえない。

## 結果

全8条件で利用可能かつ距離誤差10m未満は16/16例、利用不能と利用可能な10m以上誤差は0例だった。各セル16/16の正確95%区間は79.4〜100%であり、母集団の成功率100%を示すものではない。共通16乱数を使った128観測なので、128例の独立な成功として集計しない。

| 相対Doppler Hz | 超過経路変化率 m/s | 固定コード：距離絶対誤差中央値 m | 移動コード：同中央値 m | 対応する距離推定の最大変化 m |
|---:|---:|---:|---:|---:|
| 0 | 0 | 1.1265 | 1.1265 | 0 |
| 0.7 | −0.1332 | 0.0983 | 0.0982 | 0.0139 |
| 7 | −1.3321 | 0.1557 | 0.1608 | 0.1450 |
| −7 | +1.3321 | 0.1799 | 0.1913 | 0.1208 |

成功への回復・成功から失敗への変化は、どのDopplerでも0組。速度0ではIQだけでなく、推定結果と重みも全16組で完全一致した。

±7Hz相当では800msで反射経路長が約1.07m変わるが、今回の直接波距離推定に与えた変化は最大約15cmだった。この値は同じ雑音を使った固定コード/移動コードの推定差であり、実機の系統誤差の上限ではない。また、移動モデルを入れれば常に精度が改善するという結果でもない。

## 判断と次の段階

今回の49dB-Hz・800ms・一定の小さな経路変化率では、既存の固定コード受信機で大きな距離誤差や利用不能が増える結果は見られなかった。一方、センチメートル程度の差を調べる際には、コード遅延固定近似の影響を明示する必要がある。

新しい信号生成器を比較実験で利用できる状態にしたが、受信機や校正ゲートは変更していない。コードとキャリアの整合性を一段改善したもので、現実の森林や降雨を再現したモデルとは位置付けない。

次は一定速度の仮定を外し、反射経路の加速度による相対Dopplerの時間変化を扱う。共通ドリフトしか推定しない既存受信機では、直接波と反射波のドリフト差がモデルのずれとなるため、その影響を独立した観測で検証する。

## 監査結果

関連テスト6件が通過。監査では全128観測、64組の共有雑音、16組のゼロ速度での完全一致、経路変化量と距離評価、ソース・成果物ハッシュと過去ID非重複を確認した。8条件それぞれの完全再実行結果も一致した。
