# 動的2経路モデルの帰無校正

時間変化する反射を推定するモデルに、1経路・2経路の比較と独立した帰無校正を追加した。反射の存在を最初から仮定する前回の推定器に対し、反射なしの場合は1経路へ戻せる。

## モデルと校正

新規 `calibrated_dynamic_paths_cpu.py` は既存の動的2経路推定器を変更せず呼び出し、同じ全ブロック観測値に1経路モデルも当てはめる。1経路は時間一定の未知複素振幅と遅延の実数3パラメータ、2経路は複素振幅2個・直達遅延・過剰遅延・反射ドップラーの実数7パラメータ。両者の残差は同じ観測振幅で正規化する。

スコアは `n*log(SSE_1/SSE_2)-4*log(n)`、n=147300（10×7365複素観測の実数成分数）。反射なしでは反射遅延・ドップラーが識別されないため、標準的なカイ二乗分布や事後確率として解釈しない。実際の推定処理を含む合成帰無分布で閾値を校正する。

白色複素Gaussian雑音、基準C/N0 37 dB-Hz、PRN1、片側帯域3.6828 MHz、20 ms×10ブロック、完全な直達搬送波・航法ビット除去を固定。直達遅延は[-0.3,0.3] chip、共通位相は[-π,π]の一様乱数。反射なし299件の最大スコアを閾値にし、厳密な上回りだけを2経路候補とする。スコア通過後も既存の収束・境界・局所遅延標準偏差のガードを維持。スコア不通過は1経路へ戻し、1経路側の非収束と探索境界も利用不能にする。

独立同分布の同じ帰無分布に限り、真のスコア超過率が1%を超える校正失敗確率は `0.99**299 ≈ 0.04954` 以下。最終2経路選択はスコア超過の部分集合なので同じ上界が適用される。これは校正手続きの確率保証であり、あらゆる信号強度・位相・色付き雑音で一様に保証するものではない。校正とは別の評価で観測された比率の信頼区間とも区別する。

## 評価設計

校正299件とは異なるseedで反射なし299件を評価。反射ありは電圧比0.8、過剰遅延0.1 chip、ドップラー0 / 0.1 / 0.7 / 2.3 / 6.7 Hzと初期位相0 / π/2 / πの15条件×16件、計240件。条件間で同じ16雑音実現を共有するため、独立240試行として合算しない。校正ゲートは評価開始前に保存・固定する。

比較対象は前回の「常に2経路を当てはめ、局所ガードだけで利用可否を決める方式」。反射なしでこの方式が局所ガードを通過しても、正しい反射検出を意味しない。成功は直達波測距誤差10 m未満とし、利用不能も失敗に含める。反射ありの評価は小規模な探索的比較で、有意差による優位性の主張は行わない。

## 結果

固定した閾値は **-17.254452**。反射なし評価299件ではスコア超過0件、誤った2経路選択0件、利用不能0件、測距誤差10 m未満299件だった。常に2経路を当てはめる比較方式は247件で局所ガードを通過し、10 m未満成功は207件。帰無校正により、余分な経路を採用する問題を抑えられた。

ただし0/299の誤選択率の点ごと両側95%正確区間は0–約1.23%。この評価だけで真の誤選択率が1%未満と実証したことにはならない。上記の95%校正保証と、この評価の区間を混同しない。

反射ありの成功数（各16件）は次のとおり。「強制」は従来の2経路仮定＋局所ガード、「校正」は今回の1/2経路選択。

| ドップラー | 位相0 強制→校正 | 位相π/2 強制→校正 | 位相π 強制→校正 |
|---|---:|---:|---:|
| 0 Hz | 16→5 | 16→16 | 13→13 |
| 0.1 Hz | 16→7 | 16→16 | 12→12 |
| 0.7 Hz | 16→16 | 16→16 | 16→16 |
| 2.3 Hz | 16→16 | 16→16 | 16→16 |
| 6.7 Hz | 16→16 | 16→16 | 16→16 |

同相で0 / 0.1 Hzの反射は、1経路へ戻すことでそれぞれ11 / 9件の成功を失った。ドップラーが小さいほど200 ms内の位相変化が小さく、弱い経路の存在を確信しにくい条件である。閾値を評価結果に合わせて下げず、この感度低下を残した。0 Hz・位相πでは3件、0.1 Hz・位相πでは2件が利用不能で、両方式とも同じだった。その他は利用不能なし。0.1 Hz・位相πでは利用可能14件のうち2件が10 m誤差を超え、局所ガード通過が測距成功を保証しない点も残る。

0.7 / 2.3 / 6.7 Hzの各条件では今回16/16成功だったが、小標本・共有雑音・限定した位相と振幅の結果であり、任意の動的反射に強いとは言えない。次の課題は、誤検出率の条件を保ちながら低ドップラー同相反射の検出感度を改善すること。今回の評価データで閾値を調整した結果を独立検証として扱わない。

21テスト成功。1経路の無雑音復元、全ブロック残差、厳密な閾値比較、ガードによる利用不能を含む。監査で校正299件・評価539件の全件対応、seed分離、固定ソース、校正ゲートの再計算、全選択と集計の再計算、5件の完全再生成を確認した。比較図を comparison.png / comparison.pdf に保存した。

## 再現

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_dynamic_multipath_cpu.py tests/test_calibrated_dynamic_paths_cpu.py tests/test_calibrated_path_selection.py
# 空の出力ディレクトリでのみ実行可能
python experiments/run_cpu_dynamic_selection.py
python experiments/audit_cpu_dynamic_selection.py
python experiments/plot_cpu_dynamic_selection.py
```

出力は `output/cpu-dynamic-selection/`。すべての校正スコア、フィット、選択結果、利用不能、観測ハッシュを保存する。実測データ、動くコード遅延、残留直達搬送波、森林・降雨による測位性能は今回の対象外。
