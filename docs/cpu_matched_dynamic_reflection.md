# 平均反射を一致させた動的マルチパス対照実験

前回の動的反射実験では、時間変化による平均反射の減衰・位相変化と、雑音推定への信号混入が同時に起きていた。今回、同じ平均観測値を使う静止対照を追加し、雑音重みの変化が推定結果に与える影響を調べた。受信機のモデル・判定閾値は変更していない。

## 事前に固定した条件

PRN1、白色複素Gaussian雑音、基準C/N0 37 dB-Hz、片側帯域3.6828 MHz、20 msブロック10個、反射電圧比0.8、過剰遅延0.1 chip。相対ドップラー0.7 / 2.3 / 6.7 Hzと、初期相対位相0 / π/2 / πの9条件。各64組、計576組・1152回のフィット。各条件で新規seedの同じ64実現を共有する。条件を独立標本として合算しない。

反射係数は各20 ms内の位相回転を解析的に積分したものを使う。コード遅延は固定する狭帯域近似で、幾何学的遅延変化と周波数成分間のドップラー漏れは含まない。最大6.7 Hzの場合、L1で200 ms中に省略する過剰経路長の変化は約0.255 m。実測の森林・降雨や測位誤差の検証ではない。

対照は、動的な無雑音信号の各ブロックを全ブロック平均で置き換え、動的条件と同じ雑音を加えて作る。各条件内で平均信号と平均雑音は等しく、ブロック間の信号変動だけが異なる。両者の平均観測値の差が丸め誤差1e-15未満であることを確認し、フィットには同一の観測平均配列を渡して丸め誤差の影響も除いた。雑音重みは各条件のブロックから個別に推定する。

対照信号の生成にシミュレーションの真値を使うが、推定器には真の遅延・ドップラー・位相・雑音分散を渡さない。この対照は因果を切り分ける実験用であり、実際の受信機で使える補正法ではない。

初回順位校正の閾値 -11.266410505 を固定し、再校正なし。成功を直達波測距誤差10 m未満とし、利用不能も失敗に含めた。各条件の動的対静止対照を対応あり両側正確検定で比較し、9比較にBonferroni補正を適用。プロトコル・全タスク・ソースとゲートのハッシュを評価前に保存した。検定が非有意でも同等性を証明したとは扱わない。

## 結果と残った課題

全9条件で、静止対照と動的反射の成功・失敗の分類は各試行で一致した。9比較の補正pはいずれも1。雑音重みは変化したが、今回の64組ずつでは10 m成功判定の差を観測しなかった。同等性や任意環境での影響ゼロを意味しない。

| 0.7 Hz | π/2 | 64 | 64 | 0 |

平均反射電圧は各ドップラーで約0.774、0.549、0.167であり、前回の5/10 Hzのような完全相殺はない。雑音重みの動的・対照間RMS差は約0.0016、0.0104、0.0174。両者が利用可能な組の測距値の差は最大0.388 mあり、出力の数値が完全に同じという結果ではない。信頼区間と全推定値は report.json / evaluation.jsonl に保存した。

特に2.3 Hz・初期位相π/2では両者とも17/64件が利用不能で、静止対照でも問題が残った。動的側の全条件の利用不能29レコードの内訳は、2経路探索境界26、局所遅延情報の不足3。この件数は条件をまたぐ記述的集計であり、独立な29標本という意味ではない。次はこの境界到達を診断し、真の最小値が探索域外にあるのか、初期値・最適化・経路識別の問題なのかを調べる。境界ガードを単に外して改善扱いにはしない。

22テスト成功。監査では576組の完全性、全平均観測値の一致、固定ソース・閾値、全判定・集計の再計算、9条件の代表ケースの再生成を確認した。図は comparison.png / comparison.pdf に保存した。

```bash

```
