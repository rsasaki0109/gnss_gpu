Model & limits

¹ Illustrative canopy loss = specific loss × integrated crown density × foliage multiplier. Crown path is the union length; densities add where crowns overlap. These coefficients are uncalibrated and frequency independent. This is not an implementation fitted to ITU-R P.833, C/N0, code delay, a receiver model or a positioning-accuracy result. Wood intersections and terrain obstruction make total direct power unavailable. Canopies are ellipsoid density volumes, trunks and five branches per tree are finite cylinders; drawing tessellation is used only for display. No reflection, diffraction or diffuse scattering is implemented yet.

The forest, terrain and 1.6 m-high walking route are synthetic and generated from the exported seed/parameters. Only the GNSS broadcast orbits and GPST span come from the UrbanNav 2018-12-19 dataset used by the city lab. The ENU patch is placed at that dataset's geodetic anchor; it is not an observed forest at that location. Terrain is piecewise planar within the finite patch, and geometry outside it is not modeled. Geometry uses CPU binary64; WebGL uses Float32 only for rendering.
