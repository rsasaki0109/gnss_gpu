# 共通残留搬送波モデルの独立校正と自動経路選択

共通搬送波を遅延と同時に推定する処理に、自動の単一路／二経路選択を追加した。前回の「経路数を既知とする診断」から進め、観測から計算したスコアと新しく校正した閾値だけで経路数を選ぶ。

## 校正条件と保証の範囲

PRN1、白色雑音37 reference dB-Hz、10×20 ms、片側帯域3.6828 MHz。観測ごとに共通残留搬送波を独立に一様分布[-1,1] Hzから生成する。直達遅延と位相、雑音も既存生成器の分布に従う。

反射なしの新規299観測に、単位重みの予備推定→推定残差PSD→重み付き再推定→スコア計算という全工程を適用する。スコアの最大値を閾値とし、厳密な超過だけを二経路候補とする。独立同分布の校正標本に対し、校正で決めた閾値の真の超過確率が1%を超えてしまう確率は .99^299 = 約4.954%以下。最終的な二経路選択はスコア超過の部分集合である。

この保証は**一様分布[-1,1] Hzを含む生成分布で平均した確率**に対するもの。各搬送波残差に条件付けた1%保証、最悪条件の保証、色付き雑音や異なるC/N0への保証ではない。有限個の評価で誤判定0件になっても真の誤判定率0%を意味しない。

スコアはn log(SSE1/SSE2)−4 log(n)。単一路4実数パラメータ、二経路8実数パラメータ。スコアをカイ二乗やモデルの事後確率として解釈しない。

## 自動選択の規則

`calibrated_common_carrier_cpu.py` の選択器は、スコアが閾値以下なら単一路、超過なら二経路を要求する。要求した推定が既存の局所ガードを通らなければ利用不能（ambiguous）を返し、別モデルへのフォールバックはしない。推定器と選択器に真の経路数、搬送波、遅延を渡さない。

単一路と二経路の両方で共通搬送波を推定する。収束・探索境界・局所遅延標準偏差の検査は前回の共通搬送波モデルをそのまま利用。推定器やその探索設定を今回の結果に合わせて変更していない。

## 未使用観測での評価

校正ID800000〜800298とは別に、反射なし128観測（810000〜）、反射あり64観測（820000〜）を生成する。過去の開発観測ともIDを重複させない。搬送波は両群とも新たに独立な一様分布[-1,1] Hzから生成する。

反射ありは電圧比0.8、超過遅延0.1 chip、相対Doppler+0.7 Hz、初期相対位相0。全校正・評価タスク、ソースハッシュ、推論の範囲を実験前のprotocol.jsonに記録する。校正完了時に閾値を保存し、その後で初めて評価観測を処理する。

距離成功は絶対誤差10 m未満で、利用不能を失敗として数える。既知経路数での結果は参考診断として別に記録する。区間推定は各集計の点別Clopper–Pearson 95%区間で、同時区間ではない。旧受信機との優越性検定は行わない。

## 結果

凍結した閾値は **−24.99826377099785**。

| 条件 | 件数 | 二経路選択 | 利用不能 | 距離誤差10 m未満 | 既知経路数での距離成功 |
|---|---:|---:|---:|---:|---:|
| 反射なし | 128 | 0（偽検出） | 0 | 128 | 128 |
| 反射あり | 64 | 62 | 0 | 61 | 63 |

反射なしの偽二経路率は観測上0/128で、点別正確95%区間は **0〜2.84%**。評価標本だけでは1%以下を認証できない。校正の分布条件付き保証と、評価標本の区間推定は別の主張である。

反射ありの距離成功は61/64（95.31%、正確95%区間86.91〜99.02%）。3例の失敗を保存した。

| replica | 残差 Hz | 選択 | スコア | 距離誤差 m | 既知経路数の誤差 m |
|---:|---:|---|---:|---:|---:|
| 820024 | −0.06582 | 単一路 | −25.9457 | +10.995 | −1.479 |
| 820058 | +0.48689 | 単一路 | −30.0248 | +13.131 | +8.878 |
| 820060 | −0.02805 | 二経路 | +4.2643 | −11.719 | −11.719 |

2例はスコアが閾値に届かず単一路となった取りこぼし、1例は二経路を選び局所ガードを通っても距離誤差が10 mを超えた例である。今回の評価結果を使って閾値を下げることはしていない。

前回の開発再生から、新規データでの自動選択まで進められた。ただし本結果は白色雑音・特定反射条件・搬送波混合分布での検証に限られる。次は受信処理と閾値を固定したまま、色付き雑音や反射位相・相対Dopplerの変化に対する感度を調べる必要がある。

## 検証と再現

新しい選択器では、閾値ちょうどで単一路を選ぶこと、厳密超過で二経路を選ぶこと、両側の局所ガード、棄却時にフォールバックしないこと、非有限スコアの拒否をテストする。校正用搬送波の生成について再現性、正負の範囲、校正・評価IDの非重複も確認する。共通搬送波推定器の7テストと合わせて9テストが成功した。監査ではソースハッシュ、開発・校正・評価IDの非重複、閾値の再計算、全192件の選択と集計を確認し、校正3件・評価4件のフル再実行も完全一致した。

```bash
source /workspace/.gnss-env/activate.sh
pytest -q tests/test_calibrated_common_carrier_cpu.py tests/test_common_carrier_paths_cpu.py
# Requires an empty output/cpu-common-carrier-selection directory
python -m experiments.run_cpu_common_carrier_selection
python -m experiments.audit_cpu_common_carrier_selection
python -m experiments.plot_cpu_common_carrier_selection
```

成果物は `output/cpu-common-carrier-selection/`。protocol.json、calibration.jsonl、frozen_gate.json、evaluation.jsonl、report.json、completion.json、audit.json、comparison.png/pdfに、実験定義・全推定結果・閾値・集計・再現確認を保存する。

これは固定コード遅延の狭帯域合成モデルであり、調波間漏洩、追尾ループ、ナビゲーションビット、色付き・実測雑音、森林・雨、複数衛星PVTを含まない。距離成功を測位成功と読み替えない。
