# Filesystem-free cluster guard

Use the unchanged rbpf_cluster_batch CPU extension and frozen corrected D253
CUDA DLL. This is a distinct wrapper after the initial guard's speed rejection.
The frozen parent source SHA and accepted code families are checked on import.
Only known original filename spellings enter the native domain;unknown path
aliases fall back. No Path.resolve or file read is done in the hot guard.

The complete initial eligible AST is retained through a closure for _literal.
Every other guard name uses the same live original globals. All code,live
binding,type,buffer,policy and native-export guards stay in place. Numerical
selection,arbitrary Python ints/division,state identity,logical counters and
original centre/prior packing are unchanged. No result/model-value cache or
new native/CUDA build;prior rejected timings are retained and this variant
requires a separate complete-score experiment with its own controls.
