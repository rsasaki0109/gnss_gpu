# Historical RBPF oracle sources

These are the exact sources used by the D217-D293 performance prototypes.
They are archived numerical oracles, not the live estimator. Main retains its
newer positioning research features. The test policy routes only the frozen
likelihood fixture and joint-covariance source to these snapshots; production
imports are unchanged. Standalone historical benchmarks require an isolated
checkout matching their recorded source hashes; do not time modified helpers
or reinterpret a completed failed measurement as accepted.
