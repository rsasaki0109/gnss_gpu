# Call-local cluster parameter reuse

Explicit research wrapper over the preserved batched cluster selector and corrected register numerical DLL. For repeated selected state object identities, copy the completed 12-double parameter row from the first occurrence. A distinct equal-valued state is calculated separately. None has its own first-use row.

The full eligibility guard, selection order, thresholds, logical counters and original fallback are inherited. First-use NumPy expressions are copied from the original AST verbatim; the numerical score body, FP64 CPU/CUDA code, priors, hypotheses, observations and RNG are unchanged. The genuine identity intrinsic is captured in a closure; all original numeric globals remain live. The selected list holds state references throughout packing, so identities cannot be recycled inside the call.

The row map contains only integer identities and row indices and is discarded before returning. No cross-call values, inputs or GPU buffers are cached. Ordinary finite bounded float64 positions and exact float64 prior arrays use this path; existing policy, callback, code, type and buffer guards retain the original path for unsupported inputs. Concurrency with external input mutation is not a supported contract.

This is a complete-score component experiment. Adoption requires separately recorded controlled timings, complete PF-step screening and actual saved PF/trajectory bit comparisons. A component result alone does not establish full PF/FGO throughput or GPU coverage.
