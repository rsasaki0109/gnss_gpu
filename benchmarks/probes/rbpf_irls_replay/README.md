# Controlled IRLS replay probe

Independent explicit diagnostic DLL. Default control is off. The setter selects
the original reweight and all solves, or the D242 exact binary64 identity shortcut.
Both paths use the same workspace, output staging and completed-batch counters.
FP64, original ordered formulas and pivoting, no fast math or convergence tolerance.
No installed extension or runtime default changes. Replay timings cover the entire
likelihood score call; they do not establish PF, graph or route speed.
