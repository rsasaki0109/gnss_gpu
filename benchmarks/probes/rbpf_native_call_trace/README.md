# Optional native host-call trace

Windows-only diagnostic,not a product/default optimization. The complete
corrected register-LU translation unit is the byte-identical source prefix.
The extra rbpf_score_trace export runs a literal copy of rbpf_score with
QueryPerformanceCounter/GetThreadTimes markers and a host-only RAII exit.
Removing the seven marker/scope statements and renaming restores the whole
original function. GPU/CPU math,all calls,errors,transfers and order remain.

rbpf_score is retained for an untraced control. rbpf_trace_read reads only
the calling thread's last completed matching-owner trace. Version,generation,
frequency,count,flags,active header precedes stage/QPC/user100ns/kernel100ns
rows. Flags invalidate observation without changing numeric return behavior.
No CUDA events,additional synchronization,power controls or warm kernels.
New DLL device SASS/resources must match all original kernels before use.
This observer is not an overhead-calibrated speed or GPU utilization gate.
